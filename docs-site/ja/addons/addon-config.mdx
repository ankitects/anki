## Config JSON

アドオンでは、JSON 辞書に設定データを保存できます。既定値を含む `config.json` というファイルを同梱してください。簡単な例:

```text
    {"myvar": 5}
```

`config.md`:

```text
    このアドオンの設定に関するドキュメントです。*Markdown* 形式で記述します。
```

アドオンのコード:

```python
from aqt import mw
config = mw.addonManager.getConfig(__name__)
print("var is", config['myvar'])
```

設定がカスタマイズされていない場合は、このファイルの既定値が使われます。

設定をプログラムから変更する必要がある場合は、次のように変更を保存できます。

```python
mw.addonManager.writeConfig(__name__, config)
```

ユーザーは GUI から設定を編集することもできます。

編集した設定は `meta.json` に保存されます。

編集後に `getConfig()` を使うと、`meta.json` の設定が優先されます。`meta.json` の設定にキーがない場合は、Anki は既定の設定にフォールバックします。

`config.json` の既存キーの値を変更しても、設定をカスタマイズ済みのユーザーには古い値が引き続き表示されます。「既定値に戻す」ボタンを使った場合は除きます。

`config.json` がない場合は、`writeConfig()` を呼び出していても `getConfig()` は `None` を返します。

独自の GUI でオプションを管理するアドオンでは、設定ボタンをクリックしたときにその GUI を表示できます。

```python
mw.addonManager.setConfigAction(__name__, myOptionsFunc)
```

先頭にアンダースコアが付くキー名は使わないでください。将来 Anki が使用するために予約されています。

## ユーザーファイル

単純なキーと値以外の設定データが必要なアドオンでは、アドオンフォルダーのルートにある `user_files` という特別なフォルダーを使えます。このフォルダー内のファイルは、アドオンをアップグレードしても保持されます。それ以外のファイルは、アップグレード時にアドオンフォルダーから削除されます。

ユーザー用の `user_files` フォルダーが作成されるようにするには、アドオンを ZIP にまとめる前に `README.txt` などのファイルを中に入れておきます。

Anki がアドオンをアップグレードするとき、`.zip` 内にあるファイルのうち、`user_files` フォルダーにすでに存在するものは無視します。
