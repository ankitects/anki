---
title: "Python モジュール"
---

Anki 2.1.50 以降、パッケージ版には Python の組み込みモジュールの大半が含まれています。それ以前のバージョンには、Anki の実行に必要な標準モジュールだけが含まれています。

アドオンが同梱されていない標準 Python モジュールや、PyPI のパッケージを使う場合は、そのモジュールをアドオンに含める必要があります。

純粋な Python モジュールの場合は、通常サブフォルダーに配置して `sys.path` を調整するだけで済みます。`numpy` のように C 拡張が必要なモジュールは、各プラットフォーム向けの異なるモジュールを同梱し、Anki に含まれる Python のバージョンと互換性のあるバージョンを選ぶ必要があるため、かなり複雑になります。
