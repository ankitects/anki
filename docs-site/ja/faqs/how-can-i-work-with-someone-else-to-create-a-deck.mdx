---
title: "他の人と一緒にデッキを作るには？"
---

現在、Anki の共同作業機能には制限がありますが、複数人でコンテンツを作ることはできます。

音声や画像を含まないカードを作る場合は、Google Drive などのオンライン文書共同編集サービスを使うのが簡単です。

この方法では、スプレッドシートにカードを作成します。使用するノートタイプのフィールドごとに列を1つ用意してください。後から更新しやすくするため、最初の列には、カードを更新しても変わらない項目を置きます。好きなタイミングで一緒にカードを追加・編集できます。新規または更新したカードをコレクションに反映するときは、各自がスプレッドシートをテキストファイルに書き出し、[Anki にインポート](/manual/importing/intro)します。

画像や音声を含むカードを作る場合は、手順が複雑になります。上記の方法も使えますが、メディアファイルを別途配布する必要があります。代わりに、順番にコンテンツを作成する方法をおすすめします。たとえば、授業を共同で作る場合、学生 A が「レッスン1」デッキを作って最初のレッスンの内容を入れ、次に学生 B が「レッスン2」を作ります。各レッスンが完成したら、担当者がデッキを apkg ファイルに書き出し、アップロードやメールなどで共有します。他のメンバーはそのファイルをインポートします。

作業単位ごとにデッキを分けると、これまでの内容をすべて共有してファイルを大きくすることなく、それぞれの内容を書き出しやすくなります。インポート後は、必要に応じてデスクトップ版で別のデッキへ移動できます。

上級者は、`added:7` のような検索条件で過去7日間に追加したカードだけを含むフィルターデッキを作成し、そのデッキを書き出して共有すれば、作業単位ごとのデッキ作成を省略できます。

[AnkiHub](https://www.ankihub.net) や [AnkiCollab](https://www.ankicollab.com/) など、共同作業を支援するアドオンもあります。同様の機能を持つアドオンは、[共有アドオンのページ](https://ankiweb.net/shared/addons)で確認できます。
