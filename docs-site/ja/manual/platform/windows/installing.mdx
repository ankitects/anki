## 動作要件

最近のAnkiリリースは、次のWindows環境に対応しています。

| プロセッサーのアーキテクチャ | 必要なWindowsのバージョン |
| -------------------------- | ------------------------ |
| x64（IntelまたはAMD） | 64ビット版Windows 10（バージョン1703以降）または11 |
| ARM64 | Windows 11 |

プロセッサーのアーキテクチャを確認するには、「設定 > システム > バージョン情報」を開き、「デバイスの仕様」の「システムの種類」を確認してください。「x64 ベース プロセッサ」の場合はx64用のインストーラー、「ARM ベース プロセッサ」の場合はARM用のインストーラーを使います。

- Windows 7と8.1に対応する最後のAnkiリリースは、Anki 2.1.49です。
- 32ビット版Windowsに対応する最後のAnkiリリースは、[Anki 2.1.35-alternate](https://github.com/ankitects/anki/releases/tag/2.1.35)です。

古いコンピューターを使っている場合は、[リリースページ](https://github.com/ankitects/anki/releases)から以前のバージョンを入手できます。

## インストール

Ankiをインストールするには、次の手順に従ってください。

1. [https://apps.ankiweb.net](https://apps.ankiweb.net)から、プロセッサーのアーキテクチャに合う「Windows 10+ (x64)」または「Windows 11 (ARM)」を選んでAnkiをダウンロードします。
2. インストーラーをデスクトップまたはダウンロードフォルダーに保存します。
3. インストーラーをダブルクリックして実行します。エラーメッセージが表示された場合は、[インストール時の問題](./installation-issues)を参照してください。
4. インストールが完了したら、デスクトップに追加された星のアイコンをダブルクリックしてAnkiを起動します。

## アップグレード

Anki 2.1.6以降からアップグレードする場合は、以前のバージョンを先にアンインストールする必要はありません。Ankiが開いていれば終了し、上記のインストール手順に従ってください。アップグレードしてもカードは保持されます。

Anki 2.1.6より前のバージョンからアップグレードする場合や、標準版とalternate版を切り替える場合は、先に古いバージョンをアンインストールすることをお勧めします。これによりAnkiのプログラムデータは削除されますが、カードのデータは削除されません。

以前のバージョンに戻す場合は、必ず先に[ダウングレードの手順](http://changes.ankiweb.net)を確認して実行してください。

## アドオンの互換性

一部のアドオンは、Ankiの最新リリースで動作しないことがあります。最新版にアップグレードした後、欠かせないアドオンが動作しなくなった場合は、[リリースページ](https://github.com/ankitects/anki/releases)から以前のAnkiをダウンロードできます。
