---
title: "デッキパッケージ"
---

Anki パッケージ（`.apkg` ファイル）を使うと、他のユーザーが作成したデッキ、ノート、ノートタイプ、カードをインポートできます。[AnkiWeb](https://ankiweb.net/shared/decks)で共有されているものが一般的です。

## スケジュール

Anki パッケージにはスケジュール情報が含まれることもあります。端末間やプロフィール間でデッキを移す場合には便利ですが、他の人が共有したデッキをインポートする場合、通常、その人のカード間隔や復習履歴を引き継ぐ必要はありません。

インポートしたカードの間隔が予想より長い場合は、デッキ作成者が誤ってスケジュール情報を含めた可能性があります。[期限設定機能](../browsing#cards)を使って、インポートしたカードをリセットできます。Anki 23.10 以降では、インポート時に **Import any learning progress** を選択しないと、スケジュール情報が削除されます。この操作では、インポートしたカードの「leech」タグや「marked」タグも削除されます。

## 更新

`.apkg` ファイルをインポートすると、以前のインポートですでにコレクションにあるノートを Anki が識別します。ファイル内のノートがローカルのコピーより新しい場合、既定ではファイルの内容でノートが更新されます。

ノートタイプが変更されていると、この更新処理ができないのが一般的です（あなたまたはデッキ作成者がノートタイプにフィールドを追加した場合など）。ファイルに含まれる未登録のノートはインポートできますが、デッキ作成者が変更を加えても、以前インポートしたノートは更新されません。

### Anki 23.10 以降

Anki 23.10 では、より柔軟に更新方法を選べるようになりました。ノートとノートタイプを常に更新して変更内容を上書きするか、既存の項目を更新しないように設定できます。

あなたとデッキ作成者の両方が同じノートタイプを変更している場合は、2つのバージョンを_統合_することもできます。どちらかに含まれるすべてのテンプレートとフィールドが保持されますが、完全同期が必要になり、他の既存ノートが変更済みとして扱われることがあります。

#### デッキ作成者への注意

統合にはテンプレート ID とフィールド ID が必要です。これらは Anki 2.1.67 で導入されました。それ以前のバージョンで作成され ID がない場合は、名前を比較して同等の項目を探します。

フィールド ID とテンプレート ID を含めてノートタイプを共有する利点と、既存のノートタイプに ID を追加する方法については、[こちらのアドオン](https://ankiweb.net/shared/info/2063785767)をご覧ください。
