このページでは、Anki で利用できるすべてのフックを紹介します。[`pylib/tools/genhooks.py`](https://github.com/ankitects/anki/blob/main/pylib/tools/genhooks.py) と [`qt/tools/genhooks_gui.py`](https://github.com/ankitects/anki/blob/main/qt/tools/genhooks_gui.py) から自動生成されます。

使い方については[フックとフィルター](/addons/hooks-and-filters)をご覧ください。

### `note_will_be_added`

**引数:** <code>col: <a href='https://dev-docs.ankiweb.net/en/latest/autoapi/anki/collection#anki.collection.Collection'>anki.collection.Collection</a></code>, <code>note: <a href='https://dev-docs.ankiweb.net/en/latest/autoapi/anki/notes#anki.notes.Note'>anki.notes.Note</a></code>, <code>deck_id: <a href='https://dev-docs.ankiweb.net/en/latest/autoapi/anki/decks#anki.decks.DeckId'>anki.decks.DeckId</a></code>

ノートがコレクションに追加される前に変更できます。

このフックは、「追加」画面を使った場合と、
AnkiConnect などのアドオンがノートを追加した場合の両方で呼び出されます。インポート時には呼び出されません。
「追加」画面を変更する場合は、
`gui_hooks.add_cards_will_add_note` を使ってください。

### `media_file_filter`

**引数:** <code>txt: str</code>\
**戻り値:** <code>str</code>

メディアの読み込み元となるファイルパスを変更できます。

---

### `field_filter`

**引数:** <code>field_text: str</code>, <code>field_name: str</code>, <code>filter_name: str</code>, <code>ctx: <a href='https://dev-docs.ankiweb.net/en/latest/autoapi/anki/template#anki.template.TemplateRenderContext'>anki.template.TemplateRenderContext</a></code>\
**戻り値:** <code>str</code>

独自の `{{filters:..}}` を定義できます。

アドオンでは `filter_name` を確認し、`field_text` を変更するかどうかを判断してから返せます。
