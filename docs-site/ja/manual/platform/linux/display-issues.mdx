ハードウェアアクセラレーションは初期設定で有効になっています。画面に何も表示されないなどの問題が発生する場合は、ソフトウェアレンダリングを有効にしてみてください。

### 設定画面でのドライバーの変更

Anki 23.10以降では、「ツール → 設定」を開き、ドロップダウンメニューからグラフィックスドライバーを変更できます。

### ターミナルでのドライバーの変更

```
echo software > ~/.local/share/Anki2/gldriver6
```

初期設定に戻すには、`software`を`auto`に変更するか、このファイルを削除してください。
