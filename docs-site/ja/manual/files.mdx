## コレクションをチェックする

コレクションファイルに問題がないか、ときどき確認することをおすすめします。**ツール &gt; データベースをチェック**を選ぶと実行できます。データベースをチェックすると、ファイルが破損していないか確認し、一部の内部構造を再構築して、ファイルを最適化します。

データベースをチェックすると、タグの一覧も再構築されます。個々のデッキやカードを削除しても、Ankiは使用中のタグ一覧を更新しません。毎回更新するのは効率が悪いためです。使われなくなった古いタグを一覧から消したい場合は、データベースのチェックで削除できます。

<Note>
    未使用タグの削除は、コレクションのほかの内容と一緒に別の端末へ同期されません。そのため、各端末で個別に「データベースをチェック」を実行してください。
</Note>

Ankiは2週間に1度、自動的にコレクションを最適化します。この最適化でコレクションの動作は維持されますが、自動最適化ではエラーの確認やタグ一覧の再構築は行われません。

## ユーザーデータ

**Windows**では、最近のAnkiはコレクションファイルをAppDataフォルダーに保存します。ファイルマネージャーを開き、場所欄に%APPDATA%\Anki2と入力するとアクセスできます。古いAnkiでは、「ドキュメント」フォルダー内のAnkiというフォルダーに保存されていました。

**Mac**では、最近のAnkiはユーザーデータを~/Library/Application Support/Anki2フォルダーに保存します。~はホームフォルダーを表します。Ankiフォルダーを開くには、次の手順を行います。

1. Finderを開き、メニューバーから**移動 → フォルダへ移動**を選ぶか、<kbd>Shift</kbd>+<kbd>Command</kbd>+<kbd>G</kbd>を押します。
2. ~/Library/Application Support/Anki2と入力し、<kbd>Return</kbd>を押します。
3. Ankiプロフィール名のフォルダーを開きます。たとえば「User 1」というプロフィールのメディアは、Anki2/User 1/collection.mediaにあります。

Libraryフォルダーは初期設定で非表示ですが、この方法で開けます。Finderの**移動**メニューを開き、<kbd>Option</kbd>キーを押しながら**ライブラリ**を選び、**Application Support → Anki2**と進んでも開けます。古いAnkiでは、「ドキュメント/Anki」フォルダーに保存されます。

**Linux**では、最近のAnkiはユーザーデータを~/.local/share/Anki2に保存します。独自のデータパスを設定している場合は、$XDG_DATA_HOME/Anki2です。サードパーティ製の**Flatpak**版を使っている場合は、~/.var/app/net.ankiweb.Anki/data/Anki2/に保存されます。古いAnkiでは、~/Documents/Ankiまたは~/Ankiに保存されていました。

Ankiフォルダーには、プログラム全体とプロフィールごとの設定がprefs.dbというファイルに保存されています。

プロフィールごとに個別のフォルダーもあります。このフォルダーには次のものが含まれます。

- ノート、デッキ、カードなどを保存するcollection.anki2ファイル
- 音声と画像を保存するcollection.mediaフォルダー
- バックアップフォルダー
- システムファイル

Ankiを起動したままコレクションをコピーしたり移動したりしないでください。コレクションが破損する可能性があります。同じフォルダー内のほかのファイルも移動・変更しないでください。

## プログラムファイル

Ankiは初期設定では次の場所にインストールされます。

- Windows: %LOCALAPPDATA%\Programs\Anki
- macOS: /Applications/Anki.app
- Linux: /usr/local/share/anki

Anki 25.07から25.09.4では、インストールまたは更新時にサポートファイルをダウンロードし、次の場所に保存します。

- Windows: %LOCALAPPDATA%\AnkiProgramFiles
- macOS: ~/Library/Application Support/AnkiProgramFiles
- Linux: ~/.local/share/AnkiProgramFiles

このフォルダーを削除すると、ランチャーは新規インストール時と同じ動作になります。

AnkiProgramFilesにはランチャー以外の、Ankiの実行に必要なファイルがすべて含まれています。別のフォルダーやシステムにコピーし、AnkiProgramFiles/.venv/bin/anki（WindowsではAnkiProgramFiles\.venv\scripts\anki）を開くと、その場所からAnkiを起動できます。新しいコンピューターの初期設定の場所にコピーした場合は、ファイルの更新日時を保持していれば、ランチャーから既存ファイルを再利用できます。

詳しくは、後述のフラッシュドライブの節を参照してください。

## 起動オプション

あるコンピューターで破壊的な変更を行ってしまい、別のコンピューターに破損していないコピーがある場合は、変更を先にダウンロードせず、完全同期を行うために同期せずAnkiを起動したいことがあります。また、Ankiで問題が起きたとき、アドオンが原因か確認するため、一時的にアドオンを無効にするよう求められることがあります。両方を同時に行うには、Ankiの起動時に<kbd>Shift</kbd>キーを押したままにして、セーフモードで起動します。画面にセーフモードで起動したというメッセージが表示されるまで<kbd>Shift</kbd>キーを押し続けてください。Linuxでこの方法が使えない場合は、anki --safemodeを実行します。

起動時に独自のフォルダーを指定することもできます。これは主にポータブル版で使う上級者向けの機能です。通常は初期設定の場所を使うことをおすすめします。

別のフォルダーを指定する構文は次のとおりです。

```text
    anki -b /path/to/anki/folder
```

- 複数のプロフィールがある場合、-p &lt;name&gt;を指定すると特定のプロフィールを読み込めます。
- -p some-fake-nameを指定すると、起動時にプロフィール画面が表示されます。プロフィールを指定しない場合は、最後に使用したプロフィールが読み込まれます。
- 画面の言語を変更するには、-l &lt;iso 639-1 language code&gt;を使います。たとえば日本語なら「-l ja」です。

常に独自のフォルダーを使う場合は、Ankiのショートカットを変更できます。Windowsでは、ショートカットを右クリックして「プロパティ」を選び、「ショートカット」タブを開きます。プログラムのパスの後ろに「-b \\path\\to\\data\\folder」を追加すると、次のようになります。

```text
    "C:\Program Files\Anki\anki.exe" -b "C:\AnkiDataFolder"
```

この方法で-lオプションも指定すると、Ankiを簡単に別の言語で起動できます。

Windowsでは、スラッシュ（/）ではなくバックスラッシュ（\\）を使ってください。

Macでは、Ankiアイコンをクリックしたときの動作を変更する簡単な方法はありませんが、ターミナルから独自のベースフォルダーを指定して起動できます。

```text
    open /Applications/Anki.app --args -b ~/myankifolder
```

また、環境変数ANKI_BASEを定義する方法もあります。Windowsでは次のように設定します。

```text
    set "ANKI_BASE=C:/path/to/AnkiDataFolder"
```

LinuxとmacOSでは次のように設定します。

```text
    export ANKI_BASE="/path/to/AnkiDataFolder"
```

## Dropboxとファイル同期

Ankiフォルダーをサードパーティの同期サービスと直接同期することはおすすめしません。ファイル使用中に同期されると、データベースが破損する可能性があります。

メディアだけを同期したい場合は、外部フォルダーをDropboxなどのサービスにリンクできます。詳しくは[DropboxWiki: Dropbox外のフォルダーを同期する（archive.org）][dropboxwiki-sync-other]を参照してください。

[dropboxwiki-sync-other]: http://web.archive.org/web/20180919153730/http://www.dropboxwiki.com/tips-and-tricks/sync-other-folders

コレクションも同期したい場合は、同期フォルダーからローカルフォルダーへファイルをコピーし、Ankiを起動し、Ankiを終了してからファイルを同期フォルダーに戻すスクリプトを作成することを強くおすすめします。こうすれば、ファイルを開いている間に同期されることはありません。

## ネットワークファイルシステム

ネットワークファイルシステムではデータベースが破損することがあるため、Ankiのファイルはローカルのハードディスクに保存することを強くおすすめします。ネットワークファイルシステムしか使えない場合は、破損を検出できるよう、定期的に**ツール &gt; データベースをチェック**を実行してください。

## フラッシュドライブから起動する

Windowsでは、AnkiをUSB／フラッシュドライブにインストールし、ポータブルアプリケーションとして実行できます。以下ではUSBドライブがEドライブであるとします。必要に応じて読み替えてください。

- %LOCALAPPDATA%\Programs\Ankiフォルダーをフラッシュドライブにコピーし、E:\\Ankiのようなフォルダーを作ります。
- E:\\anki.batというテキストファイルを作成し、次の内容を記述します。

    E:\anki\anki.exe -b E:\ankidata

黒いコマンドプロンプトのウィンドウを開いたままにしたくない場合は、代わりに次のようにします。

```text
    start /b E:\anki\anki.exe -b E:\ankidata
```

- anki.batをダブルクリックすると、ユーザーデータをE:\\ankidataに保存してAnkiが起動します。

ドライブ文字を含む完全なパスが必要です。代わりに\anki\anki.exeを使うと、同期が動作しなくなります。

警告：すべての端末でドライブ文字を同じにしてください。Eドライブ用に設定した場合、Dドライブとして割り当てられたフラッシュドライブでは動作しません。

警告：フラッシュドライブがFAT32形式でフォーマットされていると、AnkiWebとのメディア同期が動作しない場合があります。メディアを正しく同期するには、NTFSでフォーマットしてください。

### Ankiランチャー

この手順はAnki 25.07から25.09.4に適用されます。

1. 最新のAnkiランチャーをダウンロードし、独自の場所（E:\Anki\Launcherなど）にインストールします。E:\Anki\Launcher\Ankiではありません。
2. ランチャーが表示されたら、インストールせずに閉じます。
3. E:\Anki\Anki.batファイルを作り、次の内容を記述します。

```bat
@echo off
echo Starting Anki...
set USB_ROOT=%~dp0
set ANKI_LAUNCHER_VENV_ROOT=%USB_ROOT%\AnkiProgramFiles
set ANKI_LAUNCHER=%USB_ROOT%\Launcher\anki
set ANKI_BASE=%USB_ROOT%\AnkiData
start /b %ANKI_LAUNCHER%
```

4. 作成した.batファイルをダブルクリックし、通常どおりAnkiをインストールします。
5. 以後は、別のコンピューターからも.batファイルをダブルクリックしてAnkiを起動できます。

**ツール &gt; アップグレード／ダウングレード**は引き続き利用できますが、インターネットに接続できる場合に限ります。

## ハードディスクにアクセスできない

Ankiフォルダー内のファイルに[書き込めない](./#user-data)場合、起動時にハードディスクへ書き込めないというメッセージが表示され、Ankiが終了します。アクセス権の修正方法が分からない場合は、コンピューターに詳しい身近な人に相談してください。

## 一時フォルダーのアクセス権

Ankiは一時データの保存に、システムの一時フォルダーを使います。不正なアプリや不具合のあるウイルス対策ソフトによってアクセス権が初期設定から変更されると、Ankiが正しく動作しません。

Windows 7の場合、次の手順で問題を修正できます。少し複雑なため、分からない場合はWindowsに詳しい人に相談してください。

1. スタートバーをクリックし、%temp%（パーセント記号も含む）と入力して<kbd>Enter</kbd>を押します。
2. 1つ上のフォルダーに移動し、tempフォルダーを探します。右クリックして「プロパティ」を選びます。
3. 「セキュリティ」タブで「詳細設定」をクリックします。
4. 「所有者」タブを開き、自分が所有者でなければ、ボタンをクリックして所有権を取得します。
5. 「アクセス許可」タブで、自分にフルコントロールがあることを確認します。初期設定のWindows 7では、c:\\users\\your-usernameから継承されます。

## コレクションの破損

Ankiはプログラムやコンピューターのクラッシュに強いファイル形式を使っていますが、Ankiを起動したままファイルを変更した場合、ネットワークドライブに保存した場合、または不具合でファイルが破損した場合は、コレクションが壊れることがあります。

**ツール &gt; データベースをチェック**を実行し、ファイルの破損が検出されるとメッセージが表示されます。**最善の復旧方法は、最新の[自動バックアップ](./#backups)から復元することです**。バックアップが古すぎる場合は、破損の修復を試すこともできます。

Linuxではsqlite3がインストールされていることを確認してください。Macには通常すでにインストールされています。Windowsでは[こちら](http://www.sqlite.org/sqlite-3_6_23.zip)からダウンロードしてください。

以下の手順で問題が起きた場合に備えて、まずcollection.anki2ファイルのバックアップを作成します。

### Linux/macOS

ターミナルを開き、コレクションが保存されているフォルダーに移動して、次のコマンドを実行します。

```text
    sqlite3 collection.anki2 .dump > dump.txt
```

作成されたdump.txtをテキストエディターで開き、最後の行を確認します。「rollback;」なら「commit;」に変更します。

次に、ターミナルで次のコマンドを実行します。

```text
    cat dump.txt | sqlite3 temp.file
```

出力先には必ずtemp.fileを指定してください。collection.anki2を指定すると、ファイルの中身が空になります。完了したら最後の手順に進みます。

### Windows

sqlite3.exeとデッキをデスクトップにコピーします。次に、**スタート &gt; ファイル名を指定して実行**を開き、cmd.exeと入力します。

最近のWindowsでは、コマンドプロンプトがデスクトップを開かない場合があります。表示されていなければ、administratorを自分のログイン名に置き換えて、次のように入力します。

```text
    cd C:\Users\Administrator\Desktop
```

続けて、次のコマンドを実行します。

```text
    sqlite3 collection.anki2 .dump > dump.txt
```

作成されたdump.txtをテキストエディターで開き、最後の行を確認します。「rollback;」なら「commit;」に変更します。

次に、ターミナルで次のコマンドを実行します。

```text
    type dump.txt | sqlite3 temp.file
```

出力先には必ずtemp.fileを指定してください。collection.anki2を指定すると、ファイルの中身が空になります。完了したら最後の手順に進みます。

### 最後の手順

エラーメッセージが表示されておらず、temp.fileが空でないことを確認します。この処理ではコレクションも最適化されるため、新しいファイルが元より多少小さくなるのは正常です。

ファイルが空でないことを確認したら、次の手順を行います。

- 元のcollection.anki2ファイルの名前を変更します。
- temp.fileをcollection.anki2に変更します。
- collection.anki2をコレクションフォルダーに戻し、古いファイルを上書きします。
- Ankiを起動し、**ツール &gt; データベースをチェック**を実行して、コレクションが正常に復元されたことを確認します。
