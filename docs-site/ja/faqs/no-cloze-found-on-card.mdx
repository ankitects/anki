---
title: "カードに穴埋めが見つからない"
---

<h2>空のカードが1枚だけある</h2>

穴埋めカードを作ると、穴埋め番号ごとに別のカードが作られます。たとえば次の内容からは3枚のカードが作られます。

```
{{c1::これ}} は {{c2::サンプル}} {{c3::文}} です。
```

後からテキストを編集して穴埋め番号を削除または変更すると、以前作られたカードが空になることがあります。たとえば、次のどちらの変更でもカード3は空になります。

```
{{c1::これ}} は {{c2::サンプル}}
```

```
{{c1::これ}} は {{c2::サンプル}} {{c1::文}} です。
```

カード3を表示すると、空のカードであることを知らせるメッセージが出ます。**Empty Cards** 機能で削除できます。デスクトップ版のメイン画面にある **Tools** メニューから機能を開き、空のカードを削除してください。削除対象として表示されたカードを事前に確認してください。判断に迷う場合は、**File > Export** からバックアップを作成してから操作します。

<h2>穴埋めカードがすべて空になる</h2>

カードテンプレートを誤って変更すると、穴埋めが表示されなくなることがあります。問題のあるカードを1枚編集し、最初のフィールド名を確認してください。通常は「Text」という名前です。その後、次の手順を行います。

- **Cards...** ボタンをクリックします。
- 表面のテキストを次の内容に置き換えます。

    ```
    {{cloze:Text}}
    ```

- 裏面のテキストも同じ内容に置き換えます。

フィールド名が `Text` 以外の場合は、`Text` を実際のフィールド名に置き換えてください。
