---
title: "Retina ディスプレイでスクリーンショットが大きくぼやける"
---

カードを編集して **Cards** をクリックし、スタイル欄の一番下に次の内容を追加すると、スクリーンショットが適切なサイズに縮小されます。

```
img[src*="Screen"] {
  zoom: 50%;
}
```

この設定はファイル名に `Screen` が含まれる画像を対象にします。macOS の既定のスクリーンショット名「Screen Shot」に適用されます。スクリーンショットに別の一貫した名前を付けている場合は、上記の行を調整できます。

スクリーンショットの名前に一貫したパターンがない場合は、角かっことその中のテキストを削除すると、すべての画像が対象になります。高解像度ディスプレイで撮影した画像は正しいサイズになりますが、他の場所から取得した画像が小さくなりすぎることがあります。現時点では、Anki が使う Web 技術に画像ごとの縮小要否を判定する方法がないため、適切な解決策はありません。Anki に追加する前に画像を縮小すれば、他の画像と混在させられますが、事前の設定が必要です。
