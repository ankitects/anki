---
title: "Anki v3 スケジューラー"
---

2021年版スケジューラー（「v3」）は、[Anki 2.1 スケジューラー](./the-anki-2.1-scheduler)（「v2」）を更新したものです。

## 有効にする

Anki/AnkiMobile 23.10 以降、AnkiDroid 2.17 以降では、v3 スケジューラーが既定かつ唯一の選択肢です。

それ以前のバージョンでは、設定画面からスケジューラーを切り替えられます。

## 互換性

v2 と v3 のスケジューラーには互換性があります。完全同期を行わずに切り替えられます。また、1台で v3 を使い、別の端末で v2 を使って同期しても、スケジュールに問題は起きません。

対応クライアント:

- Anki: 2.1.45 以降
- AnkiMobile: 2.0.75 以降
- AnkiWeb: 対応
- AnkiDroid: 2.17.0 以降

v3 スケジューラーはカードを集めて並べ替える方法が異なるため、v2 と v3 のクライアントでは、同じ日に期限を迎えるカード数や表示順が異なる場合があります。

## 変更点

### 取り消し

v3 スケジューラーは Anki の新しい取り消し機能を使います。カードに回答し、別のカードを埋め込み、さらに別のカードに回答した後、それぞれの操作を順に取り消せます。以前のスケジューラーは復習操作とそれ以外の操作の取り消しを別々に扱っていたため、一方の操作を行うと、もう一方の取り消し履歴が消えていました。

### 1日の上限

既定では、v3 スケジューラーの復習上限が新しいカードにも適用されます。復習が滞っている間は、新しいカードの追加が減ったり一時停止されたりします。たとえば、復習上限が200枚、新規カード上限が20枚で、復習カードが190枚ある場合、新しいカードは10枚だけ追加されます。これにより、復習の滞りがさらに増えるのを防ぎます。

この状態になった場合は、復習上限を増やし、新しいカードを追加する前に滞りを解消するのがおすすめです。復習が滞っていても新しいカードを増やしたい場合は、デッキオプションの **New cards ignore review limit** を有効にできます。

各デッキの上限は、そのデッキとサブデッキから集めるカード数を制御します。上限は選択したデッキから適用されるため、子デッキを選んだ場合、その親デッキの上限は適用されません。たとえば、次の上限を設定したとします。

- 親: 100
- 親::子: 30
- 親::子::孫1: 50
- 親::子::孫2: 5
- 親::子::孫3: 200

この場合:

- 孫3を選ぶと、最大200枚が出ます。
- 孫2を選ぶと、最大5枚が出ます。
- 孫1を選ぶと、最大50枚が出ます。
- 子を選ぶと、子とそのサブデッキから最大30枚が出ます。孫2からは5枚を超えて選ばれません。
- 親を選ぶと、最大100枚が出ます。そのうち子とそのサブデッキから選ばれるのは最大30枚です。

以前の Anki では、v3 スケジューラーは中間にあるデッキの上限を考慮しませんでした。そのため親デッキを選んでも、子デッキの上限は孫デッキから集めるカード数に影響しませんでした。

### 並べ替え

新しいカードと復習カードの表示順を制御するデッキオプションが追加されました。新しいカードは複数のデッキから混ぜて表示でき、復習カードは間隔やサブデッキ順に並べられます。

埋め込みが無効の場合、v3 スケジューラーでは表示順を調整して、同じノートから作られたカードを続けて表示するかどうかを選べます。

新しいカードと日をまたぐ学習カードを混ぜる設定は、設定画面からデッキオプションへ移動しました。学習時に選択したデッキのオプションが適用されます。

### 埋め込み

埋め込みを有効にすると、学習セッション開始時のカード数から、埋め込まれるカードが除外されます。以前は表裏のカードが10枚ずつあると、最初は20枚と表示され、復習に応じて減っていました。v3 では最初から10枚と表示されます。

デッキをクリックしたときに同じノートから作られたカードがスキップされるため、デッキ一覧とデッキを開いた後の概要画面では表示される枚数が異なる場合があります。概要画面には、待機中だったもののスキップされたカード数が表示されます。

日付をまたぐ学習カード（「日またぎ学習カード」）も、復習カードや新しいカードと同じように埋め込めます。

### 間隔のランダム化

間隔に加える小さなランダム遅延が、回答時だけでなく回答ボタンにも反映されます。

遅延の計算方法も改善されました。1週間未満の間隔では、より均等に遅延が割り当てられ、間隔が延びるにつれて遅延時間も滑らかに増えます。

### 日またぎ学習

日またぎ学習カードにも復習上限が適用されます。上限内に収めるカードを決めるとき、Anki は最初に日またぎ学習カード、次に復習カード、最後に新しいカードを集めます。

### フィルターデッキ

再スケジュールが無効なフィルターデッキでは、4つの回答ボタンが表示されます。各ボタンの時間遅延を設定できます。回答ボタンの遅延を `0` にすると、そのボタンを押したときカードは元のデッキに戻ります。

以前のバージョンでは「もう一度」の遅延を設定できました。「難しい」はその1.5倍、「良い」は2倍の遅延を使い、「簡単」を選ぶとカードは元のデッキに戻っていました。

## アドオンとカスタムスケジュール

v3 スケジューラーは一から書き直されているため、以前のスケジューラーのカード収集や回答処理を変更するアドオンは動作しません。スケジューラーのコードの一部だけを選んで差し替える（「モンキーパッチ」する）こともできなくなりました。そのため、大幅な作業なしに移植するのが難しいアドオンもあります。

一方、v3 スケジューラーではスケジュールをより細かく制御できます。カードを表示するとき、各回答ボタンに対応する時刻と状態が事前に計算されます。計算結果は、デッキオプション画面の下部に JavaScript コードを入力して変更できます。

入力したコードは、プリセットを使うデッキだけでなくコレクション全体に適用されます。

以下は例です。Anki の Qt5 版で使う場合は、最新の JavaScript をトランスパイルする必要があります。

```javascript
// 既存の状態を表示
console.log(JSON.stringify(states, null, 4));

// Web インスペクターが開いている場合にデバッガーを起動
debugger;

// 「難しい」ボタンが学習ステップの場合、遅延を
// 123 分に設定
if (states.hard.normal?.learning) {
    states.hard.normal.learning.scheduledSecs = 123 * 60;
}

// 再スケジュールありのフィルターデッキにも同じ変更を適用
if (states.hard.filtered?.rescheduling?.originalState?.learning) {
    states.hard.filtered.rescheduling.originalState.learning.scheduledSecs = 123 * 60;
}

// 復習で「簡単」を選んだとき、易しさ係数を0.2増やす
if (states.good.normal?.review) {
    states.easy.normal.review.easeFactor = states.good.normal.review.easeFactor + 0.2;
}
```

JavaScript で実装されているため、デスクトップ版だけでなく AnkiMobile と AnkiDroid でも利用できます。将来は AnkiWeb でも利用できる可能性があります。これにより、上級者はすべてのプラットフォームに適用される標準のスケジュール動作を調整できます。

各スケジュール状態については、[SchedulingStates](https://github.com/ankitects/anki/blob/main/proto/anki/scheduler.proto) をご覧ください。
