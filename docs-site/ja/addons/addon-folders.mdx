---
title: "アドオンフォルダー"
---

Anki のメインウィンドウで「ツール」>「アドオン」を選ぶと、最上位のアドオンフォルダーを開けます。「ファイルを表示」をクリックすると、フォルダーが開きます。アドオンをインストールしていない場合は最上位のアドオンフォルダーが表示されます。アドオンを選択していた場合は、そのアドオンのモジュールフォルダーが表示されるため、1つ上の階層に移動してください。

アドオンフォルダーの名前は、Anki 2.1 に対応して `addons21` です。`addons` フォルダーがある場合は、以前 Anki 2.0.x を使っていたことを示します。

各アドオンは、アドオンフォルダー内に個別のフォルダーを使います。Anki は、そのフォルダー内に `__init__.py` というファイルがあるかを確認します。例:

```text
    addons21/myaddon/__init__.py
```

`__init__.py` がない場合、Anki はそのフォルダーを無視します。

フォルダー名には、Python のモジュールシステムで問題が起きないよう、a～z と 0～9 の文字を使うことをおすすめします。

自分で作成するフォルダーには任意の名前を付けられますが、AnkiWeb からアドオンをダウンロードすると、Anki は次の例のようにアドオンの ID をフォルダー名に使います。

```text
    addons21/48927303923/__init__.py
```

また、Anki はフォルダーに `meta.json` ファイルを置き、アドオンの元の名前、ダウンロード日時、有効かどうかを記録します。

アドオンフォルダーにユーザーデータを保存しないでください。アドオンのアップグレード時に[削除されます](./addon-config#config-json)。

[エディターの設定](./editor-setup)の手順に沿って準備した場合、テスト時には `myaddon` フォルダーを Anki のアドオンフォルダーにコピーするか、Mac または Linux では元の場所からアドオンフォルダーへのシンボリックリンクを作成できます。
