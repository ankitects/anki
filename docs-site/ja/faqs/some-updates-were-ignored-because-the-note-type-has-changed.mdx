---
title: '「ノートタイプが変更されたため、一部の更新は無視されました」'
---

以前にインポートした共有デッキを再度インポートするとき、Anki が既存のカードを更新できるのは、次の条件を満たす場合です。

- フィールドの名前、数、順序が変更されていない。
- カードテンプレートの名前、数、順序が変更されていない。

表面・裏面のテンプレートを変更しても、更新の妨げにはなりません。

フィールドやカードテンプレートが変更されていて、更新を適用したい場合は、コレクション内のノートタイプを、インポートするデッキのノートタイプと一致させる必要があります。共有デッキを新しいプロフィールにインポートし、ノートタイプのフィールドとカードテンプレートを書き留めてから、元のプロフィールのノートタイプと比較してください。

更新は不要で、新しいカードだけを取り込みたい場合は、**Tools > Manage Note Types** 画面から古いノートタイプを削除するとインポートできることがあります。そのノートタイプに属するカードも削除されるため、既存カードを残す場合は、ブラウザー画面の **Change Note Type** を使って別のノートタイプへ手動で移動してください。

共有デッキの作成者がコレクション内で「ノートタイプを変更」を使っていると、作成者側とあなたのコピーとの関連付けが恒久的に失われます。その場合、フィールドやカードテンプレートが一致していても、`.apkg` のインポートによる更新はできません。学習画面でカードを表示しながら、[デバッグコンソール](/manual/misc#debug-console)で次のコマンドを実行すると、ノートタイプが関連付けられているか確認できます。

```
pp(card()['_note'].mid)
```

一時プロフィールにインポートした共有デッキについても同じ操作を行います。数値が一致すれば、ノートタイプの関連付けは維持されています。

共有デッキ内のフィールドが変更されていない場合は、テキストのインポートで更新を適用する方法もあります。共有デッキを一時プロフィールにインポートした後、**File > Export** でノートを txt 形式で保存します。次に元のプロフィールでテキストファイルをインポートし、変更されていないフィールドを照合先に指定します。テキストインポートで扱えるノートタイプは一度に1つだけです。ダウンロードした共有デッキに複数のノートタイプが含まれている場合は、ノートタイプごとに作業してください。詳しくは[更新](/manual/importing/packaged-decks#updating)をご覧ください。
