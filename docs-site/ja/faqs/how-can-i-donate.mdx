sidebarTitle: "寄付するには？"
description: "寄付するには？"
---

Anki は事業として運営されているため、寄付を受け付けるのは難しい状況です。その代わり、開発資金を得るために [AnkiMobile](https://apps.apple.com/us/app/ankimobile-flashcards/id373493387) を提供しています。Apple のモバイル端末で AnkiMobile を購入すると、その収益が Anki の開発支援に使われます。Android アプリをご利用の場合は、別のチームが開発する [AnkiDroid](https://opencollective.com/ankidroid) への寄付もご検討ください。

Patreon や BitCoin などを通じた寄付を希望する声もあります。しかし、法律に違反していないか、必要な税金が支払われているかを確認する仕組みの立ち上げと維持に時間がかかります。現時点では、その時間を Anki の開発に使う方がよいと考えています。

自分や友人のためにアプリを購入できない場合も、ほかの方法で支援できます。[ユーザーフォーラム](https://forums.ankiweb.net)で質問に回答していただけると助かります。開発者が回答する必要のある質問が減れば、その分 Anki の開発に時間を使えます。質問への回答に抵抗がある場合は、友人に Anki を紹介することも支援になります。
