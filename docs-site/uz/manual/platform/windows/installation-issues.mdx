Anki'ni oʻrnatishda duch kelishingiz mumkin boʻlgan ayrim xato xabarlari:

Shuningdek, [ishga tushirish muammolari](./startup-issues) sahifasiga ham qarang.

## "Error opening file for writing" xatosi

Anki va brauzeringizni yopish yordam bermasa, kompyuteringizni qayta ishga
tushiring, soʻng oʻrnatuvchi faylni yana ishga tushirib koʻring.

## Antivirus bilan bogʻliq muammolar

Antivirus dasturlari baʼzan [yolgʻon ogohlantirish](/faqs/my-antivirus-program-says-anki-is-infected)
(false positive) berib, Anki'ni xavfli dastur deb koʻrsatishi mumkin.
