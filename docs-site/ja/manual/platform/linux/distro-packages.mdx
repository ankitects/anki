Linuxディストリビューションが配布する、独自に変更されたAnkiでは、多くの問題が報告されています。

- AnkiはQtなどのサードパーティ製ライブラリに依存しています。Linuxディストリビューションでは、その影響を検証せずに、これらのライブラリを別のバージョンに差し替えることがよくあります。
- 配布されているAnkiが何年も前のバージョンだったり、安定版としての公開を意図していないアルファ版やベータ版だったりすることがあります。また、新しいバージョンの通知が届かないように、内蔵の更新確認機能を無効にしていることもよくあります。

コンパイル済みのAnkiは[https://apps.ankiweb.net](https://apps.ankiweb.net)から入手できます。必要なライブラリの大半が同梱されており、これらのバージョンで動作することを確認しています。ディストリビューションが配布するAnkiで問題が発生した場合は、まずAnki開発元が提供する最新のパッケージに切り替えてみてください。

希望する場合は、ディストリビューションが配布するAnkiを引き続き使っても構いません。ただし、問題が発生した場合は、そのディストリビューションのパッケージ管理者に報告する必要があります。
