## 逆向きカード

[カードを逆向きにする動画](http://www.youtube.com/watch?v=DnbKwHEQ1mA&yt:cc=on)をYouTubeで視聴できます。

「ookii」→「大きい」と「大きい」→「ookii」のように、両方向のカードを作成する方法はいくつかあります。最も簡単なのは、組み込みのノートタイプ「基本（反転カード付き）」を選ぶことです。このノートタイプでは、各方向のカードが1枚ずつ、計2枚生成されます。

一部の内容だけ逆向きカードを作りたい場合（重要な内容だけ逆向きでも学習したい場合や、逆向きにすると意味が通らないカードがある場合など）は、「基本（反転カードを任意で追加）」を選べます。このノートタイプでは、最初の2つのフィールドだけを入力すると順方向のカードだけが生成されます。「逆向きカードを追加」フィールドにも（「y」などを）入力すると、逆向きのカードも生成されます。このフィールドの内容がカードに表示されることはありません。

## カードの生成と削除

Ankiは表面が空のカードを作成しません。たとえば「自分のフィールド」が空で、あるカードの表面テンプレートにそのフィールドしか含まれていない場合、そのカードは作成されません。

追加済みのノートを編集すると、以前は空だったカードに内容が入った場合、Ankiはそのカードを自動的に作成します。一方、編集によって空になったカードは、データを誤って失う可能性があるため、すぐには削除されません。空のカードを削除するには、メインウィンドウでツール → 空のカードを選択してください。空のカードの一覧が表示され、削除するかどうかを選べます。

カード生成の仕組み上、個々のカードを手動で削除することはできません。ノートを次に編集したときに、そのカードが再作成されてしまうためです。代わりに、該当する条件付きフィールド置換が空になるようにしてから、「空のカード」機能を使ってください。

カードを生成するかどうかの判定では、Ankiは特殊フィールドやフィールド以外のテキストを考慮しません。たとえば表面テンプレートが次のようになっている場合、Countryが空ならカードは生成されません。

```text
    Where is {{Country}} on the map?
```

## カードの選択的な生成

一部の内容だけ追加のカードを作りたいことがあります。たとえば、単語セットのうち特に重要な語を思い出せるか確認する場合です。ノートにフィールドを追加し、追加カードを作りたいノートに「1」などのテキストを入力します。そのうえで、テンプレートにそのフィールドが空でない場合にカードを作成する条件を設定します。詳しくは、以下の「条件付き置換」を参照してください。

## 条件付き置換

フィールドが空かどうかに応じて、特定のテキスト、フィールド、HTMLをカードに表示できます。例を示します。

```text
    This text is always shown.

    {{#FieldName}}
        This text is only shown if FieldName has text in it
    {{/FieldName}}

    {{^FieldName}}
        This text is only shown if FieldName is empty
    {{/FieldName}}
```

実例として、フィールドが空でない場合にだけラベルを表示するには、次のようにします。

```text
    {{#Tags}}
        Tags: {{Tags}}
    {{/Tags}}
```

また、裏面に補足がある場合（補足があることを、解答をもう少し考えるための目印にする場合など）に、表面の特定のフィールドを青色で表示したいとします。その場合は、次のようにフィールドをスタイル設定できます。

```text
    {{#Notes}}
        <span style="color:blue;">
    {{/Notes}}

    {{FieldToFormat}}

    {{#Notes}}
        </span>
    {{/Notes}}
```

条件付き置換を使って、生成するカードを制御することもできます。Ankiは表面が空になるカードを生成しないため、この仕組みを利用できます。たとえば、表面に2つのフィールドを含むカードを考えてみましょう。

```text
    {{Expression}}
    {{Notes}}
```

通常はExpressionかNotesのどちらかにテキストがあればカードが生成されます。Expressionが空でない場合にだけカードを生成するには、テンプレートを次のように変更します。

```text
    {{#Expression}}
        {{Expression}}
        {{Notes}}
    {{/Expression}}
```

両方のフィールドが入力されていることを条件にする場合は、条件付き置換を2つ使います。

```text
    {{#Expression}}
        {{#Notes}}
            {{Expression}}
            {{Notes}}
        {{/Notes}}
    {{/Expression}}
```

この方法が機能するのは、条件付き置換をカードの**表面**に記述した場合だけです。裏面に記述すると、裏面が空のカードが生成されます。また、表面のフィールドが空かどうかを判定しているため、表面全体を条件付き置換で囲む必要があります。たとえば、次のテンプレートは期待どおりに動作しません。

```text
    {{#Expression}}
        {{Expression}}
    {{/Expression}}
    {{Notes}}
```

## 裏面が空のカード

カードの生成では、カードの表面だけが判定されます。たとえば、表面テンプレートが次のとおりで、

```text
    {{Field 1}}
```

裏面テンプレートが次のとおりだとします。

```text
    {{Field 2}}
```

Field 1が空でなければカードが生成されます。Field 2が空でもカードは生成されるため、裏面は空になります。

裏面が空のカードを避けるには、次のように、必須フィールドを条件付きで表面テンプレートに含めます。

```text
    {{#Field 2}}
        {{Field 1}}
    {{/Field 2}}
```

この設定では、Field 1とField 2の両方が空でない場合にだけカードが生成されます。

## 空のノートを追加する

Ankiで新しいノートを追加したとき、カードテンプレートとノートのフィールドを組み合わせてもカードが生成されない場合は、最初のテンプレートを使った空のカードが作成されます。これにより、内容が未完成でもノートを追加し、後からノートやテンプレートを編集して有効な状態にできます。空のノートを残したくない場合は、「空のカード」機能で削除できます。

## 穴埋めテンプレート

背景については、[穴埋め削除](../editing#cloze-deletion)の節を参照してください。

穴埋めノートタイプは、通常のノートタイプとは動作が異なります。通常のノートタイプのようにカードタイプの数を自由に設定するのではなく、ノート内のすべての穴埋め削除で共通のカードタイプを1つ使います。

上記のカード生成の説明のとおり、通常のカードは、問題側の1つ以上のフィールドが空でない場合に生成されます。穴埋めノートタイプのカードは、次の手順で生成されます。

- 表面テンプレートに、`{{cloze:FieldName}}`のような穴埋め置換が1つ以上あるかを確認します。
- 次に、FieldNameフィールド内で`{{c1::text}}`のような穴埋め参照をすべて探します。
- 異なる番号ごとにカードが生成されます。

穴埋めカードの生成方法は通常のカードと異なるため、`{{cloze:…​}}`タグは通常のノートタイプでは使えません。正しく機能するのは穴埋めノートタイプで使用した場合だけです。

条件付き生成では、表示中のカードを判別するための特殊フィールドを使えます。たとえば、1枚目の穴埋めカードには「ヒント1」フィールドを、2枚目には「ヒント2」フィールドを表示する場合、次のテンプレートを使います。

```text
    {{cloze:Text}}

    {{#c1}}
        {{Hint1}}
    {{/c1}}

    {{#c2}}
        {{Hint2}}
    {{/c2}}
```
