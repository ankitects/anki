title: "学習ツール"
---

学習画面の歯車アイコンをタップすると、ツール画面が開きます。

画面右上のボタンで、カードの文字サイズを調整できます。

「よく使う操作」には、頻繁に使う操作が表示されます。ボタンを1秒ほど長押しすると、操作の並べ替えや削除ができます。

「よく使う操作」の下には、AnkiMobile で利用できるすべての操作が一覧表示されます。操作を長押しすると、「よく使う操作」に追加できます。

## 操作

以下の操作はツール画面から実行できます。また、設定でタップ、スワイプ、トップバーに割り当てることもできます。

**追加**\
新しいウィンドウを開いて、デッキにカードを追加します。

**「もう一度」**\
解答画面で赤いボタンを選択し、カードをすぐにもう一度復習します。カードを忘れていた場合や、より頻繁に復習したい場合に使います。

**「難しい」**\
解答画面にボタンが4つあるとき、左から2番目のボタンを選択します。カードを思い出すのが難しかったことを示します。

**「良い」**\
解答画面で緑のボタンを選択します。最もよく使うボタンです。

**「簡単」**\
解答画面で右端のボタンを選択します。カードが簡単すぎるため、次の復習までの期間を長くしたい場合に使います。

**自動で次へ**\
解答を自動表示し、カードを自動で評価または埋めることができます。動作はデッキの学習オプションで設定できます。

**ボトムバー**\
解答ボタンとカード数を表示するボトムバーを表示または非表示にします。

**ブラウズ**\
カードブラウザーを開き、カードを検索・編集できます。

**カードを埋める**\
現在のカードを復習対象から除外します。翌日、またはカードの埋め込みを手動で解除したときに再び表示されます。

**ノートを埋める**\
現在のノートを復習対象から除外します。翌日、またはカードの埋め込みを手動で解除したときに再び表示されます。

**カード情報**\
現在のカードの情報を表示します。

**カードテンプレート**\
カードテンプレートを編集し、表と裏に表示するフィールドやカードのスタイルを変更できます。

**再生中の音声を5秒進める**\
再生中の音声を5秒先に進めます。

**再生中の音声を5秒戻す**\
再生中の音声を5秒前に戻します。

**カスタム学習**\
通常のスケジュール外で学習できます。カスタム学習プリセットについては、デスクトップ版のドキュメントをご覧ください。

**デッキの統計**\
デッキまたはコレクションのグラフと統計情報を表示します。

**デッキ一覧**\
デッキ一覧に戻ります。

**ノートを削除**\
現在表示中のノートと、そのノートに属するすべてのカードを削除します。複数方向で学習していない場合は、カード1枚だけを削除します。

**編集**\
現在のカードを編集します。

**空にする**\
現在のフィルターデッキからすべてのカードを削除します。

**フィルター/詰め込み学習**\
`"tag:hard"` のような検索条件で一時的なデッキを作成できます。フィルターデッキについては、デスクトップ版のドキュメントをご覧ください。

**フラグ 1～4**\
カードのフラグを設定または解除します。フラグを付けたカードは、後でブラウザー画面から簡単に見つけられます。

**マーク**\
現在のノートに「Marked」タグを追加し、検索で簡単に見つけられるようにします。

**マークして埋める**\
カードにマークを付けてから、復習対象から除外します。

**マークして停止**\
カードにマークを付けてから、停止します。

**夜間モード**\
システム設定を使わずに、ライトモードとダークモードを切り替えます。

**オフ**\
何も実行しません。特定のスワイプやタップ領域などを無効にしたい場合に便利です。ツール画面には表示されません。

**音声を一時停止**\
再生中の音声を一時停止または再開します。

**再構築**\
フィルターデッキまたはカスタム学習デッキで検索を再実行し、新たに条件に一致したカードがあれば取得します。

**音声を録音**\
一時的に自分の声を録音し、カード上の音声と比較できます。

**音声を再生**\
カードの音声を再生します。解答表示中に問題側の音声を再生するかどうかは、コンピューター版 Anki で設定できます。

**カードをリセット**\
現在のカードを新しいカードに戻します。

**スクラッチパッド**\
書き込みパッドを表示または非表示にし、復習中に文字を書く練習ができます。Anki はカードタイプごとに表示状態を記憶します。取り消しボタンをタップすると線を1つ取り消し、1秒ほど長押しするとすべての線を消去します。筆圧に対応した端末（iPhone 6S、Apple Pencil 対応 iPad）では、筆圧に応じて線の太さが変わります。

**スクラッチパッドのサイズ**\
スクラッチパッドのウィンドウサイズを変更します。

**上にスクロール**\
**下にスクロール**\
カードの内容が画面より大きい場合に、上または下にスクロールします。アナログスティックのないゲームコントローラーを使う場合に便利です。

**期限を設定**\
まだ復習カードでない場合は復習カードにし、指定した日数後に期限が来るようにします。0日を指定すると、すぐに復習できます。

**解答を表示**\
カードの問題が表示されているときに解答を表示します。

**学習オプション**\
学習オプション画面を表示します。

**カードを停止**\
検索操作で停止を解除するまで、現在のカードを復習に表示しません。

**ノートを停止**\
検索操作で停止を解除するまで、現在のノートに属するカードを復習に表示しません。

**トップバー**\
画面上部のバーを表示または非表示にします。

**ツール**\
ツール画面を表示します。

**デッキの埋め込みを解除**\
現在のデッキで埋められているカードを復習できる状態に戻します。

**取り消し**\
直前の復習を取り消します。

**ユーザー操作 1～8**

AnkiMobile 2.0.88 以降で利用できる高度な機能です。学習画面で JavaScript を実行できます。この機能は [JavaScript](/manual/templates/styling#javascript)を使うため、使用方法のサポートは提供していません。

共有デッキによっては、ヒントの表示や次の穴埋め削除を表示するなどの操作にキーボードショートカットを用意しています。その操作が公開関数として利用できる場合は、ユーザー操作が実行されたときに AnkiMobile から呼び出すよう設定できます。ゲームコントローラーから操作できるようになります。

ユーザー操作を定義するには、カードテンプレートが提供する関数を知っている必要があります。たとえば `revealNext()` 関数がある場合、次のコードで AnkiMobile に呼び出させることができます。

```
var userJs1 = revealNext;
```

共有デッキやテンプレートの作成者に、利用できる関数があるか確認できる場合があります。

標準の Anki テンプレートには操作が用意されていません。この機能は、自分で作成した操作や、一部の共有デッキ・テンプレートが提供する操作を実行するためのものです。

# 学習オプション

学習オプションはツール画面から開けます。デスクトップ版で利用できる設定のほとんどは、AnkiMobile でも変更できます。各項目の説明は[デスクトップ版のドキュメント](/manual/deck-options)をご覧ください。一部の設定は表記が異なりますが、動作はデスクトップ版と同じです。
