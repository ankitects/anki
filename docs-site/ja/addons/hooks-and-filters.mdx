フックは、アドオンのコードを Anki に接続する方法です。変更したい関数にフックがない場合は、下記の「フックを追加する」セクションをご覧ください。

「フック」には2種類あります。

- 通常のフックは、値を返さない関数です。副作用を起こすために実行され、渡されたオブジェクトを変更することもあります（例: リストに項目を追加）。
- 「フィルター」は、最初の引数を受け取り、必要に応じて変更して返す関数です。たとえば、カードの表示中にフィールドのテキストを受け取り、変更したテキストを返すフィルターがあります。

この区別が必要なのは、Python のデータ型には直接変更できるものと、文字列のように変更したコピーを作る必要があるものがあるためです。

## 新しい形式のフック

Anki 2.1.20 で新しい形式のフックが追加されました。

たとえば、学習画面でカードの表面が表示されるたびにメッセージを表示するとします。`reviewer.py` のソースコードを確認すると、`showQuestion()` 関数に次の行があります。

```python
gui_hooks.reviewer_did_show_question(card)
```

このフックが実行されたときに呼び出す関数を登録するには、アドオンに次のコードを追加します。

```python
from aqt import gui_hooks

def myfunc(card):
  print("question shown, card question is:", card.q())

gui_hooks.reviewer_did_show_question.append(myfunc)
```

複数のアドオンが同じフックやフィルターを登録できます。それぞれ順番に呼び出されます。

フックを削除するには、次のようなコードを使います。

```
gui_hooks.reviewer_did_show_question.remove(myfunc)
```

:warning: フックに登録した関数の実行中に、そのフックを変更しないでください。問題が発生します。

```
def myfunc(card):
  # これはしないでください!
  gui_hooks.reviewer_did_show_question.remove(myfunc)

gui_hooks.reviewer_did_show_question.append(myfunc)
```

すべてのフックを一覧で確認するには、[フックリファレンス](/addons/hooks-reference)をご覧ください。

前のセクションで説明した型補完を設定している場合は、IDE でもフックを確認できます。

新しい形式のフックの使用例については、[https://github.com/ankitects/anki-addons/blob/master/demos/](https://github.com/ankitects/anki-addons/blob/master/demos/)をご覧ください。

新しい形式のフックの多くは、旧形式のフック（後述）も呼び出します。そのため、古いアドオンも当面は動作します。ただし、新しい形式ではコード補完やエラーチェックが改善されるため、アドオンの作成者には新しい形式への更新をおすすめします。

### Web ビュー

Anki の画面の多くは、1つ以上の Web ビューで構成されています。Web ビューの利用を割り込んで処理するためのフックもあります。

Anki 2.1.22 以降:

- `gui_hooks.webview_will_set_content()` を使うと、各画面が Web ビューに送る HTML を変更できます。特定の画面に独自の HTML/CSS/JavaScript を追加できます。外部ページには適用されません。外部ページについては、下記の Anki 2.1.36 の説明をご覧ください。
- `gui_hooks.webview_did_receive_js_message()` を使うと、JavaScript から送信されたメッセージを受け取れます。Anki の JavaScript には、Python にメッセージを送る `pycmd(string)` 関数があります。`reviewer.py` などの画面はメッセージに応答します。このフックを使えば、独自のメッセージにも応答できます。

Anki 2.1.36 以降:

- `webview_did_inject_style_into_page()` を使うと、`load_ts_page()` で読み込まれるグラフ画面やお祝い画面などの外部ページに、スタイルやコンテンツを挿入できます。

#### Web ビューで外部リソースを管理する

`aqt.addons.AddonManager.setWebExports()` を使うと、アドオンから独自の Web アセットを公開できます。この方法で登録した Web エクスポートには、`/_addons` サブパスからアクセスできます。

たとえば、アドオンパッケージ内の `web` サブフォルダーにある `my-addon.js` と `my-addon.css` にアクセスできるようにするには、まず対応する Web エクスポートを登録します。

```python
from aqt import mw
mw.addonManager.setWebExports(__name__, r"web/.*(css|js)")
```

次に、`gui_hooks.webview_will_set_content` を購読する関数内で、対応する `web_content` フィールドにサブパスを追加します。

```python
def on_webview_will_set_content(web_content: WebContent, context) -> None:
    addon_package = mw.addonManager.addonFromModule(__name__)
    web_content.css.append(f"/_addons/{addon_package}/web/my-addon.css")
    web_content.js.append(f"/_addons/{addon_package}/web/my-addon.js")
```

`/` は OS 固有のパス区切り文字にも一致する点に注意してください。

## 旧形式のフック

Anki の旧バージョンでは `runHook()`、`addHook()`、`runFilter()` 関数を使う別のフックシステムを採用していました。

たとえば、スケジューラー（`anki/sched.py`）が埋もれたカードを検出すると、次を呼び出します。

```python
runHook("leech", card)
```

埋もれたカードが検出されたときに特別な処理（例: カードを「難しい」デッキに移動）を行うには、次のようにします。

```python
from anki.hooks import addHook
from aqt import mw

def onLeech(card):
    # スケジューラーが処理するため、.flush() を呼ばずに変更できます。
    card.did = mw.col.decks.id("Difficult")
    # カードが詰め込みデッキにあった場合は、元の期限とデッキを戻します。
    card.odid = 0
    if card.odue:
        card.due = card.odue
        card.odue = 0

addHook("leech", onLeech)
```

フィルターの例は [aqt/editor.py](https://github.com/ankitects/anki/blob/main/qt/aqt/editor.py) にあります。エディターは、フィールドのフォーカスが外れるたびに `editFocusLost` フィルターを呼び出します。アドオンはこのフィルターを使ってノートを変更できます。

```python
if runFilter(
    "editFocusLost", False, self.note, self.currentField):
    # ノートが更新されたので再読み込みを予約
    def onUpdate():
        self.loadNote()
        self.checkValid()
    self.mw.progress.timer(100, onUpdate, False)
```

この例でフィルターが受け取る引数は、変更済みかどうかを示すフラグ、ノート、現在のフィールドの3つです。変更がない場合は、受け取ったフラグをそのまま返します。変更した場合は `True` を返します。この仕組みにより、どれか1つのアドオンが変更を加えた場合に UI がノートを再読み込みして更新を表示します。

Japanese Support アドオンは、このフックを使ってあるフィールドから別のフィールドを自動生成します。以下に簡略化した例を示します。

```python
def onFocusLost(flag, n, fidx):
    from aqt import mw
    # 日本語モデルか?
    if "japanese" not in n.model()['name'].lower():
        return flag
    # 元フィールドと出力先フィールドがあるか?
    for c, name in enumerate(mw.col.models.fieldNames(n.model())):
        for f in srcFields:
            if name == f:
                src = f
                srcIdx = c
        for f in dstFields:
            if name == f:
                dst = f
    if not src or not dst:
        return flag
    # 出力先フィールドはすでに入力済みか?
    if n[dst]:
        return flag
    # 元フィールドからフォーカスが外れたか?
    if fidx != srcIdx:
        return flag
    # 元のテキストを取得
    srcTxt = mw.col.media.strip(n[src])
    if not srcTxt:
        return flag
    # フィールドを更新
    try:
        n[dst] = mecab.reading(srcTxt)
    except Exception, e:
        mecab = None
        raise
    return True

addHook('editFocusLost', onFocusLost)
```

フィルターの最初の引数は、戻り値として返す引数です。フォーカスが外れたときのフィルターではフラグですが、別のフィルターでは異なるオブジェクトの場合があります。たとえば `anki/collection.py` では、`_renderQA()` が「mungeQA」フィルターを呼び出し、カードの表と裏の生成済み HTML を渡します。`latex.py` はこのフィルターを使って LaTeX タグ内のテキストを画像に変換します。

Anki 2.1 では、エディターにボタンを追加するフックが導入されました。次のように使えます。

```python
from aqt.utils import showInfo
from anki.hooks import addHook

# 現在選択しているテキストに取り消し線を付ける
def onStrike(editor):
    editor.web.eval("wrap('<del>', '</del>');")

def addMyButton(buttons, editor):
    editor._links['strike'] = onStrike
    return buttons + [editor._addButton(
        "iconname", # "/full/path/to/icon.png",
        "strike", # リンク名
        "tooltip")]

addHook("setupEditorButtons", addMyButton)
```

## フックを追加する

フックがない関数を変更したい場合は、必要なフックを追加するプルリクエストを送ってください。

プルリクエストには、解決したい用途を記載してください。汎用的なフックは通常承認されますが、特定の用途に限定されたフックは、まず汎用的な形に作り直す必要がある場合があります。どのような変更になるかは[このプルリクエスト](https://github.com/ankitects/anki/pull/2340)をご覧ください。

フックの定義は [pylib/tools/genhooks.py](https://github.com/ankitects/anki/tree/main/pylib/tools/genhooks.py) と [qt/tools/genhooks_gui.py](https://github.com/ankitects/anki/blob/main/qt/tools/genhooks_gui.py) にあります。Anki をビルドすると、ビルドスクリプトがこれらの定義をもとにフックファイルを自動更新します。

詳しくは、ソースツリーの [docs/](https://github.com/ankitects/anki/tree/main/docs) フォルダーをご覧ください。
