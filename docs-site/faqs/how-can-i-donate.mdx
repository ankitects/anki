Anki does not accept direct donations. [AnkiMobile](https://apps.apple.com/us/app/ankimobile-flashcards/id373493387)
is a paid app, not a donation.

If you use the Android app, you can donate to [AnkiDroid](https://opencollective.com/ankidroid),
which is developed by a different team.

For other ways to contribute, see [Contributing](/manual/contrib).
