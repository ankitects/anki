---
title: "共有デッキの JavaScript が動作しない"
---

共有デッキの中には、カードの表示を動的に変更する「JavaScript」という機能を使うものがあります。JavaScript は壊れやすいため、Anki のマニュアルではデッキ作成者に使用しないよう勧めています。Anki の更新後や、デッキ作成者が Anki の各プラットフォームで JavaScript をテストしていない場合に、動作しなくなることがあります。

共有デッキで JavaScript のエラーが出る場合は、共有デッキのダウンロードページにレビューを投稿し、作成者や他のユーザーに知らせてください。作成者が活動していれば、今後の更新で修正される可能性があります。

作成者が対応できない場合は、エラーが表示されないようカードテンプレートから JavaScript を削除できます。JavaScript の処理内容によっては、機能の一部が失われます。

デスクトップ版 Anki で次の操作を行います。

- **File > Export** を使い、スケジュール情報を含めてコレクション全体を書き出します。問題が起きたときに戻せるバックアップになります。
- カードを編集し、**Cards...** ボタンをクリックします。
- 表面と裏面のテンプレートで、`<script>` から始まり `</script>` で終わる箇所を探します。開始タグと終了タグ、およびその間の内容をすべて削除します。
- 復習画面でエラーなくカードが表示されることを確認します。問題がなければ、変更を AnkiWeb と他の端末に同期します。
- スクリプトを削除したことでカードが完全に壊れた場合は、**File > Import** を使い、作成したバックアップを復元します。
