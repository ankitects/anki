---
title: "AnkiWeb にファイルサイズの上限はありますか？"
---

AnkiWeb のコレクションは、圧縮時に100MB、展開時に250MBまでです。カードのテキストとスケジュール情報が対象ですが、別に保存される音声や画像は含みません。

ほとんどのユーザーは上限に達しません。平均的なサイズのカードが25,000枚あり、数年分の復習履歴があっても約25MBです。通常は、各カードに大量のテキストを貼り付けるか、実際には学習しない新しいカードを何十万枚もコレクションに入れない限り、上限には達しません。

現在、メディア全体のサイズに上限はありませんが、個々のメディアファイルは100MBまでです。

Anki と AnkiWeb の利用が増えれば、将来、容量の小さい基本アカウントは無料で、より多くの容量を必要とするユーザーは追加料金を支払う料金体系を導入する可能性があります。

コレクションのサイズ上限に達すると、AnkiWeb への一方向アップロード時に、コレクションの状態に不整合があるというメッセージが表示されます。大きなコレクションは他のユーザーの AnkiWeb の動作を遅くするため、上限を引き上げることはできません。辞書1冊分の内容をインポートした場合は、使っていないカードを別のデッキへ移動し、そのデッキを書き出してからコレクションから削除してください。その後、**Tools > Check Database** を実行すると、削除したカードが使っていた領域を解放できます。
