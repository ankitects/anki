---
title: "フォントを変更する"
---

<h2>Anki</h2>

- 復習中に表示されるフォントを変更するには、[こちら](/manual/templates/styling)をご覧ください。
- カードの追加・編集時に表示されるフォントは、**Fields** ボタンから変更します。
- ブラウザーのカード一覧に表示されるフォントは、**Cards**、**More**、**Browser Appearance** の順にクリックして変更します。
- ボタンやメニューなどには、システムのフォント設定が使われます。システムのフォントサイズを調整すると、表示サイズを変更できます。Anki だけフォントを変更する場合は、[Change Interface Font](https://ankiweb.net/shared/info/1431333984) アドオンをインストールしてください。

<h2>AnkiMobile</h2>

- カードテンプレートの変更は、AnkiMobile での学習にも反映されます。
- 復習中に青い歯車をタップすると、デスクトップ版に対するフォントの拡大率を調整できます。
