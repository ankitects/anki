Anki's Rust API documentation is generated from doc comments in the `rslib/`
crates using `cargo doc`.

To browse the docs locally:

```
cargo doc --open
```

The main crates are:

- **anki** (`rslib/`) - Core library
- **anki_io** (`rslib/io/`) - I/O utilities
