ブラウザー画面では、カードやノートを検索して編集できます。メイン画面の**ブラウズ**をクリックするか、<kbd>B</kbd>キーを押すと開きます。画面は3つの領域で構成されています。左側の _サイドバー_、右上の _カード/ノート一覧_、右下の _編集領域_ です。領域の境界にマウスポインターを置いてドラッグすると、一方を広げ、もう一方を狭められます。

## 一覧の表示モード

![一覧の表示モード](/media/browser_table_modes.png)

Anki 2.1.45以降では、一覧にカードを表示するモードとノートを表示するモードを切り替えられます。検索欄の左上にある切り替えボタンをクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>T</kbd>または<kbd>Cmd</kbd>+<kbd>Opt</kbd>+<kbd>T</kbd>を押してください。切り替えボタンには、現在カード（**C**ards）とノート（**N**otes）のどちらを表示しているかも示されます。

**注:** 説明を簡潔にするため、このマニュアルでは通常、カードモードを使う前提で説明します。「カードを選ぶ」「カードを見つける」などと書かれている場合は、現在のモードに応じて「カードまたはノート」と読み替えてください。

## サイドバー

左側の _サイドバー_ から、よく使う検索語にすばやくアクセスできます。Anki 2.1.45以降では、検索欄、タグやデッキの編集機能、2種類のツールも利用できます。ツールの詳細は以下で説明します。サイドバー上部のツールバー、または<kbd>Alt</kbd>+<kbd>1</kbd>/<kbd>2</kbd>のショートカットでツールを切り替えます。

### 検索ツール

![検索ツール](/media/browser_search_tool.png)

このツールでは、以前のバージョンと同様に、項目をクリックするとその項目で検索します。

クリック時に<kbd>Ctrl</kbd>（Macでは<kbd>Command</kbd>）を押し続けると、新しい検索を始めずに、クリックした項目をAND条件として現在の検索に追加できます。たとえば、ドイツ語デッキにある学習中のカードを表示するには、「Learning」をクリックしてから、<kbd>Ctrl</kbd>を押しながら「German」をクリックします。

<kbd>Shift</kbd>を押すと、AND検索ではなくOR検索になります。たとえば、デッキを1つクリックしてから、<kbd>Shift</kbd>を押しながら別のデッキをクリックすると、どちらかのデッキにあるカードを同じ画面に表示できます。

<kbd>Alt</kbd>（Macでは<kbd>Option</kbd>）を押すと、検索条件を反転し、先頭に`-`を付けます。たとえば、現在のデッキにあるカードのうち、特定のタグが付いていないものを表示できます。<kbd>Alt</kbd>/<kbd>Option</kbd>は<kbd>Ctrl</kbd>または<kbd>Shift</kbd>と組み合わせられます（たとえば<kbd>Ctrl</kbd>+<kbd>Alt</kbd>を押しながらクリックすると、否定条件の検索語が追加されます）。

Anki 2.1.39以降では、検索語をクリックするときに<kbd>Ctrl</kbd>と<kbd>Shift</kbd>を同時に押すと、同じ種類の検索条件をすべて新しい条件に置き換えられます。たとえば、以前に`deck:Swahili (is:due or tag:important)`のような複雑な検索式を入力し、同じ検索をウルドゥー語デッキに対して行いたいとします。サイドバーのウルドゥー語デッキをクリックするときに<kbd>Ctrl</kbd>+<kbd>Shift</kbd>を押すと、検索式は`deck:Urdu (is:due or tag:important)`になります。

### 選択ツール

![選択ツール](/media/browser_selection_tool2.png)

選択ツールでは、<kbd>Ctrl</kbd>または<kbd>Shift</kbd>を押しながらクリックして、複数の項目を同時に選択できます。ドラッグ＆ドロップでデッキやタグの順序を変更することもできます。

例として、「Math」「Calculus」「Algebra」というタグがあるとします。「Calculus」をクリックし、<kbd>Ctrl</kbd>を押しながら「Algebra」をクリックします。2つのタグを選択した状態で、どちらかを「Math」へドラッグすると、両方がその子タグになります。Ankiは内部で2つのタグ名をそれぞれ`Math::Calculus`と`Math::Algebra`に変更し、ノートにも反映します。

複数の項目を選択して検索することもできます。項目を選択して右クリックし、**検索 &gt; 選択したすべて/いずれか**を選びます。[検索ツール](./#search-tool)の修飾キーと組み合わせて、検索結果を現在の検索に追加できます。

### 保存した検索

同じ検索を繰り返し使う場合は、サイドバーの一番上の項目を右クリックし、**現在の検索を保存**を選んで名前を入力すると、検索を保存できます。サイドバーの項目をこの領域へドラッグ＆ドロップして、同じ検索を追加することもできます。保存した検索は上部に固定されます。

### 項目の編集

サイドバーから、または右クリックメニューやショートカットキー（Windowsでは<kbd>Del</kbd>と<kbd>F2</kbd>）を使って、タグ、デッキ、保存した検索を削除または名前変更できます。複数の項目を一度に削除することもできます（[選択ツール](./#selection-tool)を参照）。

### 項目を探す

サイドバーのツリー内で項目を探すには、上部の検索欄に名前の一部を入力します。

## 検索欄

カード一覧の上に検索欄があります。カードを検索するには、ここに検索語を入力します。検索構文については、[検索](./searching)を参照してください。

## カード/ノート一覧

一覧の各行には、現在の検索に一致したカードまたはノートが表示されます。行をクリックすると、対応するノートが下の領域に表示されます。

### 行

マウスで複数行を選択するか、<kbd>Ctrl</kbd>または<kbd>Command</kbd>を押しながらクリックすると、編集領域は一時的に非表示になります。デッキの変更など、カードモードとノートモードのどちらでも複数のカードやノートに対して実行できる操作があります。そのため、カードモードでは、カードが1枚でも選択されていればそのノートも選択されたものとみなされます。ノートモードでは、ノートが選択されていればそのカードも選択されたものとみなされます。

カード情報の表示など、1枚のカードまたは1つのノートだけを対象とする操作もあります。これらの操作の対象を _現在の_ カードまたはノートと呼び、通常は最後に選択またはクリックしたものが該当します。カードモードでは現在のノートは現在のカードが属するノートです。ノートモードでは現在のカードは現在のノートの最初のカードです。

カードとノートの状態に応じて、背景色が変わります。カードモードでは、次の順に判定されます。

1. カードに**フラグ**が付いている場合は、そのフラグの色。
2. カードが**停止中**の場合は、黄色。
3. カードのノートに**マーク**が付いている場合は、紫色。

ノートモードでは、マークされたノートだけに色が付きます。マークされたノートと停止中のカードについては、[編集などの操作](./studying#editing-and-more)を参照してください。

### 列

表示する列は変更できます。列を右クリックするか（Macでは<kbd>Ctrl</kbd>を押しながらクリック）、表示したい列を選びます。列をドラッグすると順序を変更できます。列をクリックすると、その列で並べ替えます。もう一度クリックすると、並び順が反転します。「問題」と「答え」の列では並べ替えできません。

[カードモードとノートモード](./#table-modes)のどちらでもすべての列を利用できますが、列名やデータが少し異なる場合があります。各モードでの動作は次のとおりです。

{/* prettier-ignore */}
| 列 | カードモード | ノートモード |
| --- | --- | --- |
| 答え | 問題を除いたカードの裏面を1行で表示します。カードタイプの編集画面で[カスタム書式](./templates/styling#browser-appearance)を選ぶこともできます。 | カードモードと同じ内容を、そのノートの最初のカードについて表示します。 |
| カード | カードのテンプレート名です。 | ノートに含まれるカード数です。 |
| カードの更新日時 | カードが最後に変更された日時です（例: カードを復習し、復習履歴や間隔が更新された日時）。 | ノートのカードのいずれかが最後に変更された日時です。 |
| 作成日時 | カードが属するノートについて、ノートモードと同じ内容を表示します。 | ノートを作成した日付です。 |
| デッキ | カードが属するデッキ名です。 | ノートのカードが属するデッキの数です。すべて同じデッキにある場合は、デッキ名を表示します。 |
| 期限 | 復習中または（再）学習中のカードでは期限日、新規カードでは新規カードキュー内の位置です。カードが停止中または埋められている場合、値を括弧で囲みます。種類ごとに並べ替えてから、日付または位置で並べ替えます。 | 停止中、埋められている、またはカスタム学習デッキ内にあるカードを除き、次に期限を迎える復習または（再）学習カードの日付です。 |
| （平均）易しさ | 新規カード以外の場合、そのカードの易しさです。 | 新規カード以外のカードについて、ノート内のカードの平均易しさです。 |
| （平均）間隔 | 復習中または再学習中の場合、そのカードの間隔です。 | 復習中または再学習中のカードについて、ノート内のカードの平均間隔です。 |
| 失敗回数 | 「もう一度」と評価された回数です。 | ノート内のすべてのカードの失敗回数の合計です。 |
| ノート | カードが属するノートについて、ノートモードと同じ内容を表示します。 | ノートタイプ名です。 |
| ノートの更新日時 | カードが属するノートについて、ノートモードと同じ内容を表示します。 | ノート（フィールドの内容など）を最後に編集した日時です。 |
| 問題 | カードの表面を1行で表示します。カードタイプの編集画面で[カスタム書式](./templates/styling#browser-appearance)を選ぶこともできます。 | カードモードと同じ内容を、そのノートの最初のカードについて表示します。 |
| 復習回数 | カードを復習した回数です。 | ノート内のすべてのカードの復習回数の合計です。 |
| ソートフィールド | カードが属するノートについて、ノートモードと同じ内容を表示します。 | ノートタイプでソートフィールドに指定されたフィールドの内容です。表示や並べ替えに使えるのは、このフィールドだけです。編集領域の**フィールド...** をクリックすると、ソートフィールドを変更できます。 |
| タグ | カードが属するノートについて、ノートモードと同じ内容を表示します。 | ノートのタグです。 |

## 編集領域

右下の領域には、選択した行のノートが表示されます。カードとノートについて詳しくは、[はじめに](./getting-started)を参照してください。書式設定ボタンについては、[編集](./editing)を参照してください。

編集領域上部の**プレビュー**ボタンをクリックすると、現在選択しているカードが復習時にどう表示されるか確認できます。答えを入力するフィールドは表示されません。これにより、カードをすばやくプレビューできます。ノートモードでは、選択したノートの最初のカードがプレビューされます。

## メニューと操作

ブラウザー上部のツールバーには、ブラウザー内で実行できる操作を含むメニューがあります。

### 編集

{/* prettier-ignore */}
| 名前 | 操作 |
| --- | --- |
| 元に戻す | 最後に実行した操作を取り消します。 |
| すべて選択 | 表示中の行をすべて選択します。 |
| ノートを選択 | 現在選択しているノートだけを表示し、すべての行を選択します。 |
| 選択を反転 | 未選択の行を選択し、選択中の行を選択解除します。 |
| カスタム学習デッキを作成 | [カスタム学習デッキ](./filtered-decks#creating-manually)のダイアログを開き、現在のブラウザー検索をフィルターに設定します。<kbd>Alt</kbd>/<kbd>Option</kbd>を押すと、2つ目のフィルターとして設定できます。 |

### ノート

以下の操作の多くは、選択したノートを対象にします。ノートモードで選択行を右クリックしたときのコンテキストメニューからも実行できます。カードモードでは、コンテキストメニューのサブメニューにあります。

{/* prettier-ignore */}
| 名前 | 操作 |
| --- | --- |
| ノートを追加 | [追加](./editing#adding-cards-and-notes)ダイアログを開きます。 |
| コピーを作成 | 現在のノートの[複製](./browsing#finding-duplicates)を[編集画面](./editing#adding-cards-and-notes)で開きます。少し変更するだけでカードのバリエーションを簡単に作れます。初期設定では、複製したカードは元のカードと同じデッキに作成されます。 |
| ノートを書き出す | [書き出し](./exporting)ダイアログを開きます。 |
| タグを追加 | 入力したタグを、選択したすべてのノートに追加します。 |
| タグを削除 | タグを入力し、選択したすべてのノートから削除します。 |
| 未使用のタグを消去 | どのノートにも使われていないタグを、サイドバーからすべて削除します。 |
| マークを切り替える | 現在のノートに「Marked」タグが付いている場合、選択したすべてのノートからマークを外します。付いていない場合は、すべてにマークを付けます。 |
| ノートタイプを変更 | 選択したノートを別のノートタイプに変換します。たとえば、「Russian」ノートタイプにコンピューター関連のテキストを誤って追加した場合、「Computer」ノートタイプへ変更できます。カードのスケジュールには影響しません。ノートタイプの変更には一方向同期が必要です。 |
| 重複を検索 | [重複](./#finding-duplicates)ダイアログを開きます。 |
| 検索と置換 | [検索と置換](./#find-and-replace)ダイアログを開きます。 |
| ノートタイプを管理 | [ノートタイプ](./editing#adding-a-note-type)ダイアログを開きます。 |
| 削除 | 選択したすべてのノートとカードを削除します。個々のカードは[テンプレート](./templates/intro)によって作られるため、カードだけを削除することはできません。 |

### カード

以下の操作は、選択したカードを対象にします。カードモードで行を右クリックしたときのコンテキストメニューからも実行できます。ノートモードでは、コンテキストメニューのサブメニューにあります。

{/* prettier-ignore */}
| 名前 | 操作 |
| --- | --- |
| デッキを変更 | 選択したカードを別のデッキへ移動します。 |
| 期限日を設定 | 新規カードを復習カードにし、特定の日を期限にします。学習予定が中断したときに、カードを数日先または前に移動するのに便利です。`60-90`のような範囲を入力すると、選択したカードの期限を今日から60〜90日後に設定します。新規カードの間隔は同じ日数に設定されます。復習カードは、範囲の末尾に感嘆符（`!`）を付けない限り、現在の間隔を変えずに再スケジュールされます。手動でスケジュールしたカードには回答時間が記録されません。この操作は復習中以外にも実行でき、その時点でどのカードが表示されているかAnkiには分からないためです。 |
| リセット | 選択したカードを新規カードキューの末尾へ移動します。既存の復習履歴は保持されます。Anki 2.1.50以降では、カードの元の位置を復元するオプションと、失敗回数や反復回数をリセットするオプションがあります。 |
| 配置を変更 | 新規カードの表示順を変更します。既存の位置は、上の[一覧](./#cardnote-table)で説明したように「期限」列を表示すると確認できます。複数のカードを選んで配置変更を実行すると、各カードに順番に増加する番号が割り当てられます。初期設定では番号はカードごとに1ずつ増えますが、「ステップ」の設定で変更できます。「既存カードの位置をずらす」を有効にすると、既存カードの間にカードを挿入し、既存カードを後ろへずらせます。たとえば、カードが5枚あり、3、4、5を1と2の間に移動したい場合、この設定を選ぶと1、3、4、5、2の順になります。無効にすると、1と2に同じ位置番号が割り当てられ、同じ番号のどちらが先に表示されるかは予測できません。この設定を有効にした場合、より後ろの位置にあるカードも変更されます。変更されたカードは、次回同期時にすべて送信されます。 |
| 停止を切り替える | 現在のカードが停止中かどうかに応じて、選択したカードを[停止](./studying#editing-and-more)または停止解除します。 |
| フラグ | 選択したカードのフラグを切り替えます。現在のカードに選択したフラグが付いているかどうかに応じて、フラグを付けるか外します。 |
| 情報 | 現在のカードに関する情報を表示します。復習履歴も確認できます。詳しくは[カード情報](./stats#card-info)を参照してください。 |

このメニューには、ブラウザー内の各領域へ移動するショートカットと、カード一覧を上下に移動するショートカットがあります。

## 検索と置換

このダイアログでは、ノート内のテキストを置換できます。前述のとおり、ツールバーまたは一覧のコンテキストメニューから開けます。

最初の入力欄には置換対象のテキストを、2つ目には置換後のテキストを入力します。次に、Ankiがどこから置換対象を探すかをドロップダウンメニューで指定します。ノートのタグ（Anki 2.1.45以降が必要）、すべてのフィールド、または特定のフィールドを選べます。特定のフィールドを選ぶ場合、選択中のノートにあるフィールドだけが一覧に表示されます。

初期設定では、選択したノートだけが対象です。この制限を解除するには、「選択したノートのみ」のチェックを外します（Anki 2.1.45以降が必要）。

正規表現を使うと、複雑な置換ができます。たとえば、フィールドに次のテキストがあるとします。

```text
    <img src="pic.jpg" />
```

次の設定を使います。

![検索と置換ダイアログ](/media/find_and_replace.png)

（Anki 2.1.28より前のバージョンでは、`${1}`を`\1`に置き換える必要があります。）

この場合、フィールドの内容は次のように変わります。

```text
    pic.jpg
```

正規表現の詳しい説明は、この文書の範囲外です。構文ガイドはウェブ上で公開されています。

- Anki 2.1.28以降は、[regexの構文ガイド](https://docs.rs/regex/latest/regex/index.html#syntax)を参照してください。
- それ以前のAnkiでは、[Pythonの構文ガイド](http://docs.python.org/library/re.html)を参照してください。

## 重複を検索

**ノート &gt; 重複を検索**を使うと、同じ内容を持つノートを検索できます。ウィンドウを開くと、Ankiはすべてのノートタイプを確認し、選択できるフィールドを一覧表示します。「Back」フィールドの重複を調べる場合は、一覧から選択して**検索**をクリックします。

初期設定では、指定したフィールドを持つすべてのノートタイプが検索対象です。これは、カードを手動で追加するときに行う重複チェックとは異なります。手動追加時のチェック対象は、1つのノートタイプに限られます。

**任意のフィルター**欄を使うと、重複を検索する範囲を絞り込めます。「French Vocab」と「French Verbs」のノートタイプだけを検索する場合は、次のように入力します。

```text
    "note:french vocab" or "note:french verbs"
```

特定のデッキだけを検索するには、次のように入力します。

```text
    "deck:myDeck"
```

検索構文はブラウザーでの検索と同じです。詳しくは[検索](./searching)を参照してください。
