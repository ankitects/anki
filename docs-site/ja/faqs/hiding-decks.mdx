---
title: "デッキを非表示にする"
---

しばらく勉強する予定はないものの、デッキを削除したくない場合は、非表示にできます。方法は2つあります。

**A) デッキを書き出して削除する**

1. **File → Export** を選び、_Export Format_ の一覧から `Anki Deck Package (*.apkg)` を選びます。
2. _Include_ の一覧から削除するデッキを選びます。
3. _Include scheduling information_ と _Include media_ にチェックが入っていることを確認してください。チェックがないと、再び使うときに復習履歴やメディアが失われる可能性があります。
4. **Export** をクリックし、後で見つけられる場所に apkg ファイルを保存します。
5. 最後に、コレクションからデッキを削除します。

デッキを戻すには、**File → Import** を選び、書き出したデッキをインポートします。書き出し時と同じ名前で復元されます。

**B) 「未使用」デッキを作る**

デッキ一覧でドラッグ＆ドロップすると、デッキを階層化できます。この機能とオプショングループを組み合わせて、使う予定のないデッキを非表示にできます。

1. **Create Deck** をクリックし、「Unused」「Hidden」などの名前でデッキを作ります。名前の前にチルダ（`~`）（例: `~Unused`）を付けると、一覧の下部に表示できます。
2. 非表示にするデッキを、新しいデッキの下へドラッグします。名前の横にあるマイナス記号をクリックして、Unused デッキを折りたたみます。
3. これで十分ならここで終了できます。ただし、この状態では期限到来数が引き続き表示されます。表示しないようにする場合は、手順4に進みます。
4. Unused デッキの横にあるオプションボタンをクリックし、**Options** を選びます。
5. 右上のオプションボタンをクリックして、新しいオプショングループを追加します（「unused deck」などの名前を付けます）。
6. **New Cards** タブで、1日あたりの新規カード数を `0` に設定します。**Reviews** タブでは、1日あたりの最大復習数を `0` に設定します。

デッキを戻すには、メインのデッキ一覧へドラッグします。一覧の一番上または一番下に置くと、最上位のデッキになります。Unused デッキは次回のために残しておけます。
