---
title: "文字サイズ"
---

文字の大きさが適切でない場合は、次の2つの環境変数を試してください。

- ANKI_NOHIGHDPI=1を設定すると、Qtの高DPI対応の一部を無効にします。

- ANKI_WEBSCALE=1を設定すると、メニューバーなどのインターフェース要素はそのままで、デッキ一覧や学習画面など、AnkiのWebビューの表示倍率を変更します。1を、1.5や0.75など、希望する倍率に置き換えてください。

Windowsでは、これらをバッチファイルに書くと、Ankiを簡単に起動できます。たとえば、デスクトップにstartanki.batという名前のファイルを作り、次の内容を記入します。

```text
    set ANKI_WEBSCALE=0.75
    start "Anki" "%LocalAppData%\Programs\Anki\anki.exe"
```

保存後にファイルをダブルクリックすると、その設定でAnkiを起動できます。
