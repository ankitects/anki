---
title: "重複したノートタイプを削除する"
---

Anki をしばらく使っていると、`Basic-908e4`、`Cloze-37a28`、`Image Occlusion++++` のように、同じ名前に異なる文字が付いたノートタイプが複数できることがあります。コレクションにすでにあるノートタイプと同じ名前のノートタイプを使った共有デッキをインポートした場合や、重複する名前でノートタイプを作った場合に起こります。Anki は既存のノートタイプとの統合や上書きを避けるため、名前に文字を追加します。

このような「重複」したノートタイプは通常問題ありませんが、どれを使っているか分かりにくくなることがあります。整理するには次の手順を行います。

1. **Manage Note Types** ウィンドウ（**Notes → Manage Note Types**）で **Fields** と **Cards** をクリックし、各ノートタイプのフィールド、カードテンプレート、スタイルを比較します。
    - 同じ内容なら、削除するノートタイプを決め、**Rename** をクリックして名前を変更します（例: 名前に `-delete` を付ける）。
    - 内容が異なる場合は、一方をより分かりやすい名前に変更して、両方を残します。
2. **Browse** ウィンドウの左側サイドバーで削除するノートタイプを選び、**Edit → Select All** ですべてのノート/カードを選択します。
3. **Notes → Change Note Type** を選び、画面右側のドロップダウンから残すノートタイプを選択します。この操作の後、AnkiWeb と同期する際に一方向同期が必要になります。他の端末に未同期の進捗がある場合は、ここで中止して各端末を同期してください（Anki からも警告が表示されます）。フィールドとテンプレートの対応が正しいことを確認して、**Save** をクリックします。
4. 削除するノートタイプごとに手順2と3を繰り返します。
5. **Manage Note Types** ウィンドウを再度開き、使われなくなったノートタイプを削除します。それぞれ「[0 notes]」と表示されます。
