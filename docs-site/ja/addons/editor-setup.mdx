title: "エディターの設定"
---

メモ帳のような基本的なテキストエディターでもアドオンを書けますが、適切な Python エディターや開発環境（IDE）を設定すると、作業がずっと楽になります。

## PyCharm の設定

PyCharm の無料の Community Edition は、Python を標準でよくサポートしています。[https://www.jetbrains.com/pycharm/](https://www.jetbrains.com/pycharm/) をご覧ください。Visual Studio Code など、ほかのエディターも使えますが、PyCharm が最も使いやすいと考えています。

この1年ほどで、Anki のコードベースではほぼすべてのコードに型ヒントが追加されました。型ヒントは、コード補完を改善し、mypy などのツールでエラーを検出できるため、開発をしやすくします。アドオンの開発でも型ヒントを利用できます。

最初のアドオンを作るには、次の手順に沿ってください。

- PyCharm を開き、新しいプロジェクトを作成します。
- 左側のプロジェクトを右クリック（または Ctrl+クリック）し、`myaddon` という名前の Python パッケージを作成します。

次に、型補完を使えるよう Anki のソースコード一式を取得します。Anki 2.1.24 以降では、これらを PyPI から入手できます。**64 ビット版の Python を使用し、インストールする Anki のバージョンがサポートする Python のバージョンを使う必要があります。** PyCharm から Anki をインストールするには、左下の「Python Console」をクリックし、次を入力します。

```python
import subprocess

subprocess.check_call(["pip3", "install", "--upgrade", "pip"])
subprocess.check_call(["pip3", "install", "mypy", "aqt[qt6]"])
```

Enter キーを押して、処理が完了するまで待ちます。完了すると、コード補完が使えるようになります。

エラーが発生する場合は、64 ビット版以外の Python を使っているか、現在の Anki バージョンがサポートしていない Python を使っている可能性があります。詳しい情報を得るには、上記のコマンドに `-vvv` を付けて実行してみてください。

インストール後、`__init__.py` ファイルをダブルクリックして、コード補完を試します。画面下部に処理中のアイコンが表示された場合は、完了するまで待ってください。次を入力します。

```python
from anki import hooks
hooks.
```

補完候補が表示されます。

**PyCharm からアドオンを実行することはできません。実行するとエラーになります。** アドオンは Anki 内で実行する必要があります。詳しくは[基本的なアドオン](./a-basic-addon)をご覧ください。
