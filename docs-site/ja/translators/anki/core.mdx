title: "共通インターフェース"
---

[翻訳サイト](https://i18n.ankiweb.net/projects/)の `core` モジュールでは、Fluent という翻訳システムを使用しています。[Fluent](https://projectfluent.org/)は比較的新しいシステムで、翻訳者が複数形を扱いやすくし、開発者が翻訳の参考になるコメントを付けやすくします。

`core` モジュールの翻訳は複数のファイルに分かれており、スケジューリングやデッキオプションなど、それぞれ特定のトピックを扱います。[こちら](https://i18n.ankiweb.net/en-GB/core/)で確認できます。

## 単純な置き換え

![単純な翻訳文字列](/media/simple-replacement@2x.png)

テキストが単純な文字列の場合は、母語でテキストを入力して「Save」をクリックするか、Enter キーを押すだけです。

英語のテキストの下には、その文字列が使われる場所や表示例を説明するコメントが付いていることがあります。

「Context」はこの文字列の短い名前です。使われる場所や表している内容の手がかりになることがあります。

## 変数

![変数を含む翻訳文字列](/media/variable@2x.png)

英語のテキストに `{$something}` とある場合、その部分が別の内容に置き換わることを示します。翻訳では `{$something}` の位置を変えられますが、中のテキストは変更しないでください。`{...}` の中を翻訳する必要はありません。英語のテキスト内にある `{$something}` をクリックすると、翻訳欄に自動でコピーできます。

## 複数形

多くの言語では、数によって単語の形が変わります。たとえば英語では「1 cat」「3 cats」のように変わります。

翻訳対象の文字列には、次のようなものがあります。

![複数形を含む翻訳文字列](/media/simple-plurals@2x.png)

上の部分には、英語の2つの形式、`one`（秒）と `other`（秒）が表示されています。

下の部分にはポーランド語の翻訳が表示されています。ポーランド語には4つの複数形があります。この例では、`few` と `many` に同じ訳が使われています。

翻訳サイトには、お使いの言語に応じた数の入力欄が自動で表示されます。日本語のように複数形を分けない言語では、翻訳を一度入力するだけで済みます。

## 高度な複数形

翻訳サイトには、より柔軟に翻訳できる高度なモードがあります。左下の FTL アイコンをクリックすると切り替えられます。先ほどの例は次のように表示されます。

![高度な複数形を使った翻訳文字列の編集](/media/advanced-plurals@2x.png)

1行目は、このメッセージを識別する一意の ID です。コメントの近くにある「CONTEXT」ラベルにも表示されます。

残りの部分は、次のような意味です。

- `amount` の値を確認する
- `amount` が `one` の場合は `{$amount} sekunda` を表示する
- `amount` が `few` の場合は `{$amount} sekundy` を表示する
- `amount` が `many` の場合は `{$amount} sekund` を表示する
- `amount` が `other` の場合は `{$amount} sekundy` を表示する

`few`、`many`、`other` の定義は[言語](https://unicode.org/cldr/charts/latest/supplemental/language_plural_rules.html)によって異なります。

`other` の前にある `*` は、該当する形式がほかにない場合に `other` を使うことを示します。この例では `few` と `other` が同じなので、次のように短くできます。

```
time-span-seconds = { $amount ->
  [one]   { $amount } sekunda
  [many]  { $amount } sekund
 *[other] { $amount } sekundy
 }
```

ここでは `few` を個別に指定していないため、`other` の場合が適用されます。ただし、翻訳サイトに未翻訳の形式があるという警告を出さないためにも、通常はすべての形式を列挙するのが最善です。

これらのルールを手動で記述する場合は、最初の行を除く各行の先頭に、少なくとも1つのスペースを入れてください。

この例では書き換えによる利点はあまりありませんでしたが、言語によっては英語の文字列の構造にそのまま当てはめにくいため、この柔軟性が役立ちます。

たとえば、Anki のブラウザー画面でカードを表示すると、新しいカードには「New #1」や「New #532」のように番号が付きます。英語ではこの場合に複数形を使いませんが、ほかの言語では必要になることがあります。

これをスペイン語に翻訳する場合、次の画面が表示されます。

![複数形を追加する翻訳文字列の編集](/media/advanced-plurals2@2x.png)

複数形を追加するには、FTL ボタンをクリックし、次のようにテキストを変更します。

```
due-for-new-card = { $number ->
  [one]   Nueva #{ $number }
 *[other] Nuevas #{ $number }
 }
```

もう1つ例を見てみましょう。この場合、英語のテキストにも複数形がありますが、変更が必要なのは一部だけです。ポーランド語に翻訳する場合、「used by」の部分も変える必要があります。そのため、通常の編集画面では不十分です。

![複数形の別の例](/media/advanced-plurals3@2x.png)

これを修正するには、FTL ボタンをクリックして空のテンプレートを表示します。

![複数形のテンプレート表示](/media/advanced-plurals4@2x.png)

次に、必要に応じてテンプレートを変更します。

![複数形のテンプレート表示を変更](/media/advanced-plurals5@2x.png)

## ほかの言語

訳し方が分からない場合は、右側の「Locales」タブをクリックしてください。その画面で翻訳の概要を確認したり、特定の言語を選んですべての複数形の訳を確認したりできます。

## 特殊文字

翻訳文字列が複数行にわたる場合は、`.` または `[` で始まる行に注意してください。文字列の1行目はこれらの文字で始めても構いませんが、複数行の翻訳では問題の原因になります。

たとえば、次の形式は問題ありません。

```
some-translation =
  This is a translation that occurs
  over ... two
  or three lines.
```

一方、次の形式では、2行目が `[`、3行目が `.` で始まるため問題が発生します。

```
some-translation =
  [This is a translation that occurs over
  ...two
  or three lines.]
```

複数行の文字列で行頭に `[` または `.` を使う場合は、`{"` と `"}` で囲んでエスケープしてください。たとえば次のようにします。

```
some-translation =
  {"["}This is a translation that occurs over
  {"."}.. two
  or three lines.]
```

## テスト

Anki のベータ版がリリースされるたびに、前回のリリース以降に行われた翻訳の変更が含まれます。アプリ内での表示を確認できるよう、ベータ版をお試しください。ベータ版の更新情報は、サポートサイトのベータテストのセクションで確認できます。

翻訳の長さは、できるだけ英語の原文と同程度にしてください。長さをそろえられず、ベータ版でテキストが正しく表示されない場合（ラベル同士が重なるなど）は、サポートサイトに問題を報告してください。

ベータ版をテストしていて、翻訳できないテキストに気づいた場合も、修正できるようサポートサイトに報告してください。
