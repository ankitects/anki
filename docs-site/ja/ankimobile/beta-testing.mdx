title: "AnkiMobile のベータテスト"
---

## 参加する

ベータテストには、AnkiMobile をすでに利用している方が参加できます。参加するには、App Store から最新バージョンをインストールし、AnkiWeb と同期している必要があります。

参加を希望する場合は、招待を依頼する[非公開チケット](https://anki.tenderapp.com/discussions/private)を投稿してください。AnkiMobile の同期に別のメールアドレスを使っている場合は、メッセージに AnkiWeb ID も記載してください。

## ベータ版と通常版を切り替える

ベータ版と通常版を切り替えても、端末内のカードは保持されます。念のため、バージョンを切り替える前に変更内容を AnkiWeb に同期してください。

招待を受け取ったら承諾し、App Store から TestFlight アプリをインストールしてください。TestFlight アプリから最新のベータ版をダウンロードできます。新しいベータ版が公開されると通知が届き、任意のタイミングでアップグレードできます。

App Store 版に戻すには、AnkiMobile の App Store ページを開き、雲のアイコンをタップします。App Store 版に戻ると、以前と同じように通常のアプリ更新を受け取れます。

ベータテストを終了し、今後の通知も受け取りたくない場合は、TestFlight アプリから登録を解除できます。

ベータ版で問題が発生した場合は、[非公開チケット](https://anki.tenderapp.com/discussions/private)を投稿するか、フォーラムの[ベータテストのセクション](https://forums.ankiweb.net/c/anki/beta-testing/13)に投稿してください。
