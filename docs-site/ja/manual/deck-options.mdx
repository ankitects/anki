title: "デッキオプション"
---

デッキオプションでは、主にAnkiがカードをスケジュールする方法を設定します。設定を変更する前に、まず初期設定のまま数週間使い、Ankiの動作を把握することをおすすめします。設定を理解してから変更してください。誤った設定はAnkiの効果を損なうことがあります。

コンピューターでは、次のいずれかの方法でデッキオプションを開きます。

- デッキ画面で歯車アイコンをクリックする。
- デッキ画面でデッキを選び、画面下部の**オプション**をクリックする。
- 復習中に**その他 &gt; オプション**を選ぶ。
- 復習中に<kbd>O</kbd>キーを押す。

デッキオプションについて、コミュニティに投稿された記事を紹介します。

- [デッキオプションの解説](https://forums.ankiweb.net/t/deck-options-explained/213)
- [デッキオプションの全体像](https://forums.ankiweb.net/t/deck-options-in-a-mental-map/15757)

## プリセット

複数のデッキでオプションを共有すると、一度に設定を更新できるため便利です。設定は _プリセット_ にまとめられています。プリセット内のオプションを変更すると、同じプリセットを使うすべてのデッキに変更が適用されます。新しく作成したデッキはすべて「Default」プリセットを使います。

他のデッキには反映せず、1つのデッキだけ設定を変えるには、デッキオプション画面の右上にある矢印アイコンをクリックします。次の操作ができます。

- **保存:** デッキオプションで行った変更をすべて保存します。
- **プリセットを追加:** 初期設定のオプションを持つ新しいプリセットを、このデッキに追加します。
- **複製:** 現在のプリセットを複製します。一部のオプションだけを変更し、他の設定を維持したい場合に便利です。
- **名前を変更:** 現在のプリセットの名前を変更します。
- **削除:** 現在のプリセットを削除します。次回の同期は[一方向同期](./syncing#conflicts)になります。
- **すべてのサブデッキに保存:** **保存**と同じ操作を行い、現在選択しているデッキのすべてのサブデッキにも選択中のプリセットを割り当てます。

デッキオプションの変更は過去にさかのぼって適用されません。たとえば、カードを間違えた後の待ち時間を設定するオプションを変更しても、変更前に間違えたカードには新しい待ち時間ではなく、以前の待ち時間が適用されます。

## サブデッキ

デッキにサブデッキがあり、その一部に親デッキとは異なる設定を使いたい場合は、サブデッキに別のプリセットを割り当てます。Ankiはカードを表示するとき、そのカードがどのサブデッキに属するかを確認し、そのデッキのオプションを使います。ただし、次の2つは例外です。

- サブデッキの「1日の新規カード数」と「1日の最大復習数」の[上限](./#daily-limits)は、そのサブデッキから集めるカード数に影響します。ただし、学習セッションで表示されるカードの合計数は、学習対象として選んだデッキの上限で決まります。
- [表示順](./#display-order)のオプションは、現在のカードのデッキではなく、学習対象として選んだデッキから取得します。

たとえば、次のコレクションがあるとします。

```text
    - Deck A (Preset 1)
      - Deck A::Subdeck B (Preset 2)
```

Preset 1とPreset 2は、次の2点を除いて同じ設定です。

- Preset 1:
    - **学習ステップ:** `1m 10m`
    - **新規/復習の順序:** `復習と混ぜる`
- Preset 2:
    - **学習ステップ:** `20m 2h`
    - **新規/復習の順序:** `復習の後に表示`

Subdeck Bを学習対象に選ぶと、次のようになります。

- すべての新規カードの学習ステップは`20m 2h`です（Preset 2が適用されます）。
- 新規カードはすべて復習カードの後に表示されます（Preset 2が適用されます）。

Deck Aを学習対象に選ぶと、次のようになります。

- Deck Aの新規カードの学習ステップは`1m 10m`です（Preset 1が適用されます）。
- Subdeck Bの新規カードの学習ステップは`20m 2h`です（Preset 2が適用されます）。
- 新規カードはすべて復習カードと混ぜて表示されます（Preset 1が適用されます）。

## 1日の上限

### 1日の新規カード数 {#new-cardsday}

プログラムを開いた日に、導入できる新規カードの数を設定します。上限より少ない枚数しか学習しなかった場合や、1日休んだ場合でも、翌日の上限は初期設定に戻ります。上限を超えるカードが追加で表示されることはありません。

サブデッキを含むデッキを学習する場合、各サブデッキに設定した上限は、そのデッキから取得するカードの最大数を決めます。選択したデッキの上限は、表示されるカードの合計数を決めます。

以前のバージョンについては、[こちらのよくある質問](/faqs/the-anki-2.1-scheduler)を参照してください。

新規カードを学習すると、1日に必要な復習回数は一時的に増えます。新しく学んだ内容は、復習間隔が十分に長くなるまで何度か繰り返す必要があるためです。毎日20枚の新規カードを継続して学習する場合、1日の復習はおよそ200枚になると予想できます。復習の負担が減るまで、1日に導入する新規カードを減らすことで、必要な復習を減らせます。Ankiを使い始めた数日間に何百枚もの新規カードを学び、その後、必要な復習に追われてしまう人もいます。

### 1日の最大復習数 {#maximum-reviewsday}

1日に表示する復習カード数の上限を設定します。この上限に達すると、期限のカードが残っていても、その日はそれ以上表示されません。継続して学習している場合、この設定で期限カード数の一時的な増加を抑えられます。また、1週間休んだ後にAnkiを再開したとき、復習数に圧倒されるのを防げます。このオプションによって復習カードが非表示になった場合、お祝い画面にメッセージが表示され、時間があれば上限を増やすよう提案されます。

サブデッキを含むデッキを学習する場合、復習数の上限は新規カード数の上限と同様に動作します。

Ankiは、[日付をまたいだ](./preferences#scheduler)学習中カード（翌日以降に復習する学習中カード）も復習数に含めます。そのため、これらのカードにも復習数の上限が適用されます。

### デッキごとの1日の上限

同じプリセットを複数のデッキで使いながら、それぞれに異なる上限を設定できます。この機能を使えば、上限だけを変えるためにプリセットを複製する必要がなくなり、サブデッキごとの上限も設定しやすくなります。

1日の上限には、次の3つの設定方法があります。

- **プリセット:** そのプリセットを使うすべてのデッキに適用します。
- **このデッキ:** 特定のデッキだけに適用します。
- **今日のみ:** 特定のデッキだけに一時的に適用します。

### 新規カードには復習数の上限を適用しない

初期設定では、復習数の上限は新規カードにも適用されます。復習数が上限に達すると、新規カードは表示されません。このオプションを有効にすると、復習数の上限にかかわらず新規カードが表示されます。

期限を過ぎた復習カードが大量に残っている場合は、追いつくまで新規カードの導入を止めることをおすすめします。復習が遅れている状態で新規カードを追加し続けると、未処理のカードがさらに増えることがあります。

### 上位デッキから上限を適用する

初期設定では、サブデッキを選ぶと、上位デッキの1日の上限は適用されません。親デッキの新規カード上限が1日10枚、サブデッキの上限が1日20枚の場合、親デッキの上限はサブデッキから学習できる新規カード数に影響しません。

このオプションを有効にすると、サブデッキを選んだ場合にも、上位デッキの上限が適用されます。先ほどの例では、サブデッキから学習できる新規カードは20枚ではなく10枚です。

サブデッキを個別に学習しながら、すべてのサブデッキのカード数に合計上限を設けたい場合に便利です。

## 新規カード

このセクションのオプションは、新規カードと[学習中カード](./getting-started#card-states)にだけ適用されます。カードが学習ステップをすべて終えて卒業すると、このセクションのオプションは適用されなくなります。

### 学習ステップ

学習の反復回数と、その間隔を設定します。1つ以上の間隔をスペースで区切って入力してください。復習中に**正解**をクリックするたびに、カードは次のステップへ進みます。**もう一度**をクリックすると、最初のステップに戻ります。

学習ステップが`1m 10m 1d`の場合を考えます。

- **もう一度**をクリックすると、カードは最初のステップに進み、1分後に再表示されます。
- 新規カード、または1分のステップ後に**正解**をクリックすると、次のステップに進み、10分後に再表示されます。
- 10分のステップ後に**正解**をクリックすると、翌日まで待ちます。
- 翌日にカードで**正解**をクリックすると卒業し、復習カードになります。カードは _卒業間隔_ で設定した期間の後に再表示されます。

**難しい**ボタンの動作は、現在のステップによって異なります。

- 最初のステップでは、**難しい**を選ぶと`6m`後に表示されます。これは最初の2つのステップ（`1m`と`10m`）の平均です。
    - 例外: 学習ステップが1つだけの場合、**難しい**を選ぶとそのステップの1.5倍の間隔になります。この間隔が学習ステップより長くなるのは最大1日です。
- それ以外のステップでは、**難しい**を選ぶとそのステップを繰り返します。

他に学習するカードがない場合、初期設定ではAnkiが学習中カードを最大20分早く表示します。この機能を無効にする、または先読み時間を変更するには、[設定](./preferences)を参照してください。

#### 日付の境界

Ankiは、短いステップと、[日付をまたぐ](./preferences#review)ステップを別々に扱います。短いステップでは、指定した間隔が経過すると、復習カードや新規カードより優先してすぐに表示されます。設定した間隔にできるだけ近い時期に答えられるようにするためです。一方、ステップが日付をまたぐ場合、間隔は自動的に日数へ換算されます。たとえば、翌日まで5時間で、間隔が6時間の場合、Ankiは間隔を1日に換算します。

### 卒業間隔

最後の学習ステップで**正解**を選んだ後、カードを再表示するまでの日数です。学習カードが卒業した後の最初の間隔を指します。[学習ステップの例](./deck-options#learning-steps)を参照してください。

### 簡単間隔

カードで**簡単**を選んだ後、再表示するまでの日数です。

**簡単**を選ぶと、現在のステップにかかわらず学習中カードは復習カードになり、このオプションで設定した間隔が適用されます。簡単間隔は卒業間隔以上に設定し、通常はさらに数日長くします。

### 挿入順

新規カードをデッキにランダムまたは順番どおりに追加するかを設定します。このオプションを変更すると、現在のプリセットを使うデッキの並べ替えが行われます。

最近のバージョンのAnkiでは、このオプションを`Sequential`のままにし、代わりに[表示順](./deck-options#display-order)を調整してください。

## 失敗したカード

復習カードで**もう一度**をクリックすることを _失敗_ と呼びます。このセクションのオプションは、失敗したカードに適用されます。

### 再学習ステップ

失敗したカードに対する学習ステップです。復習カードで**もう一度**を押すと、再び復習カードになる前に _再学習ステップ_ を進みます。

ステップを空欄にすると、再学習を行わず、初期設定では新しい間隔が1日に設定されます。

### 最小間隔

再学習を終えたカードが再表示されるまでに必要な最小日数を設定します。初期設定は1日です。再学習が終わると、翌日に再表示されます。

### 何度も失敗するカード

何度も失敗するカードをAnkiがどう扱うかを設定します。詳しくは[何度も失敗するカード](./leeches)を参照してください。
## 表示順

このセクションのオプションは、現在表示中のカードのデッキではなく、学習対象として選んだデッキから取得されます。

表示順について詳しくは、[学習](./studying#display-order)のセクションを参照してください。

### 新規カードの取得順

デッキから新規カードを取得する順序を設定します。

- **デッキ順:** 上位から順に各サブデッキを確認し、カードを取得します。各サブデッキでは、位置の小さいカードから取得します。選択したデッキの1日の上限に達すると、すべてのサブデッキを確認する前に取得を終了することがあります。大きなコレクションでも処理が速く、一覧の上にあるサブデッキを優先できます。

    デッキとサブデッキは常にアルファベット順に並びます。順序を指定するには、`001`のような数字を名前の先頭に付けます。`_`や`~`を先頭に付けて、項目を先頭または末尾に配置することもできます。

    位置の順序は初期状態では挿入順に基づきますが、[ブラウザー](./browsing#cards)でカードの位置を変更する方法もあります。

- **デッキ順、ノートはランダム:** 上位から順に各サブデッキを確認し、ランダムに選んだノートからカードを取得します。

- **位置の昇順:** 位置（期限番号）の小さい順にカードを取得します。通常、追加時期が古いカードから表示されます。

- **位置の降順:** 位置（期限番号）の大きい順にカードを取得します。通常、追加時期が新しいカードから表示されます。

- **ノートをランダムに選択:** ランダムに選んだノートからカードを取得します。

- **カードをランダムに選択:** カードをランダムな順序で取得します。

### 新規カードの並べ替え順

新規カードを取得した後に並べ替える順序を設定します。

- **カードタイプ順、取得順:** カードタイプ番号順に表示し、同じカードタイプのカードは取得した順に表示します。同じノートのカードを埋める機能を無効にしている場合、表→裏のカードをすべて見てから裏→表のカードを見る順序になります。同じノートのカードが近い間隔で表示されないようにしたい場合に便利です。

- **取得順:** 取得した順にそのまま表示します。同じノートのカードを埋める機能が無効の場合、通常、同じノートのカードが連続して表示されます。

- **カードタイプ順、ランダム:** カードタイプ番号順に並べ、各カードタイプ内のカードをシャッフルします。同じノートのカードを近い間隔で表示せず、ランダムな順にしたい場合に便利です。

- **ノートをランダムに選択してカードタイプ順:** ノートをランダムに選び、同じノートのカードをカードタイプ順に表示します。

- **ランダム:** 取得したカードをすべてシャッフルします。

### 新規カードと復習カードの順序

新規カードを復習カードと混ぜるか、復習カードの前または後に表示するかを設定します。

### 日をまたいだ学習カードと復習カードの順序

日付をまたいで（再）学習するカードを、復習カードと混ぜるか、復習カードの前または後に表示するかを設定します。学習中カードは復習カードより難しい傾向があるため、簡単なカードを先に終わらせる目的で最後に表示したり、忘れたカードの復習時間を長く取るために最初に表示したりする人もいます。

### 復習カードの並べ替え順

復習カードを並べる順序を設定します。

- **期限日順、ランダム:** 初期設定では、長く待っているカードを優先します。期限どおりに学習できている場合や、未処理のカードが少ない場合におすすめの順序です。長期間休んだ後や、復習が遅れている場合は、一時的に並べ替え順を変えることを検討してください。
- **期限日順、デッキ順:** 長く待っているカードを優先し、その後、サブデッキごとに復習カードを表示します。
- **デッキ順、期限日順:** サブデッキごとに復習カードを表示します。同じ順序で繰り返し学習すると、文脈から答えを推測しやすくなり、記憶が弱くなるため、通常はおすすめしません。
- **間隔の昇順:** 間隔の短いカードから表示します。
- **間隔の降順:** 間隔の長いカードから表示します。
- **易しさの昇順:** 難しいカードから表示します。
- **易しさの降順:** 易しいカードから表示します。
- **相対的な期限超過度:** 忘れている可能性が高いカードから表示します。未処理のカードが多く、すべて終えるまで時間がかかりそうな場合におすすめです。多くのカードを忘れる可能性を下げられます。

    SM-2アルゴリズムを使っている場合、期限超過度は、期限をどれだけ過ぎているかと現在の間隔を比べて決まります。たとえば、現在の間隔が5日で2日遅れているカードは、間隔が10日で3日遅れているカードより先に表示されます。

    FSRSを有効にすると、この並べ替え順は使えません。FSRSで同等の順序は**想起可能性の昇順**です。各カードの想起可能性（思い出せる確率）と、プリセットで設定した希望保持率をもとに計算されます。

## 埋める

Ankiはカードを取得するとき、まず当日中の学習カード、次に日付をまたいだ学習カード、その後に復習カード、最後に新規カードを取得します。この順序は、カードを埋める動作に影響します。

- すべての埋める設定を有効にしている場合、この順序で先にある兄弟カードが表示されます。たとえば、新規カードより復習カードが優先されます。
- 後の種類の兄弟カードが、前の種類のカードを埋めることはありません。たとえば、新規カードを埋める設定を無効にして新規カードを学習しても、日付をまたいだ学習カードや復習カードは埋められません。同じ学習セッションで、復習カードと新規カードの両方が表示されることがあります。

設定項目は次のとおりです。

- **新規カードの兄弟を埋める:** 同じノートの他の新規カード（逆向きカードや隣接する穴埋めなど）を翌日まで遅らせるかどうかを設定します。
- **復習カードの兄弟を埋める:** 同じノートの他の復習カードを翌日まで遅らせるかどうかを設定します。
- **日をまたいだ学習カードの兄弟を埋める:** 同じノートにある、日付をまたいだ他の学習カードを翌日まで遅らせるかどうかを設定します。

カードを埋める機能について詳しくは、マニュアルの[このセクション](./studying#siblings-and-burying)を参照してください。

## 音声

- **音声を自動再生しない:** 初期設定では、カードにある音声をAnkiが自動再生します。このオプションを有効にすると、音声再生キーの<kbd>R</kbd>または<kbd>F5</kbd>を押すまで音声は再生されません。

- **答えの再生時に問題側をスキップ:** 答え側で再生操作をしたとき、問題側の音声も再生するかを設定します。Ankiは`{{FrontSide}}`フィールドの音声を[自動再生しません](./templates/fields#special-fields)。このオプションは自動再生の動作には影響しません。

## タイマー

<a id="timer"></a>

Ankiはカードに答えるまでの時間を測定し、1日に学習した時間を表示します。回答にかかった時間はスケジュールに影響しません。

### 内部タイマー

- **回答時間の上限:** 初期設定は60秒です。これより時間がかかると、Ankiはコンピューターから離れたか、気が散ったと判断します。不正確な統計にならないよう、記録時間は60秒で上限になります。
- 内部タイマーは問題が表示されてから、回答を評価するボタンを押すまで動作します。カード1枚にいつも60秒以上かかる場合は、上限を増やすこともできますが、カードをより簡潔にすることをおすすめします。

### 画面上のタイマー

- **画面上にタイマーを表示:** 学習画面に、カードの学習時間を計るタイマーを表示します。このタイマーは、内部タイマーで設定した回答時間の上限に達すると停止します。
- **答えを表示したらタイマーを停止:** 答えを表示してから評価ボタンを押すまで、画面上のタイマーを動かし続けるかを設定します。このオプションは、統計に記録される時間には影響しません。

## 自動送り

Anki 23.12以降が必要です。自動送りを使うと、一定時間が経過した後に操作を自動で実行できます。利用するには、まず**問題を表示する秒数**または**答えを表示する秒数**に0以外の時間を設定してください。その後、学習画面の**その他**ボタンから自動送りを開始します。

## 学習しやすい曜日

日曜日など、週の特定の日にAnkiの学習時間を減らしたい場合に使える機能です。間隔を計算した後、期限日を調整するために少し変更します。すべての曜日を「減らす」または「最小」に設定しても、「通常」に設定した場合と学習量は変わりません。この機能はFSRSと従来のSM-2アルゴリズムの両方で使えます。

学習しやすい曜日の設定を変更しても、既存の間隔にはさかのぼって適用されず、今後の間隔だけに影響します。期限のカード数はすぐには変わりません。

## FSRS

[Free Spaced Repetition Scheduler (FSRS)](https://github.com/open-spaced-repetition/fsrs4anki/wiki/ABC-of-FSRS)は、Ankiの従来のSuperMemo 2（SM-2）アルゴリズムに代わるスケジューラーです。忘れる可能性をより正確に判断することで、同じ学習時間でより多くの内容を覚えられるようにします。

FSRSを有効にすると、一部のオプションが追加され、**卒業間隔**や**簡単ボーナス**などSM-2専用のオプションは非表示になります。この設定はすべてのプリセットで共有されます。

**有効にする前に**

- 使用しているAnkiクライアントがすべてFSRSに対応していることを確認してください。Anki 23.10、AnkiMobile 23.10、AnkiWebは対応しています。AnkiDroidは2.17以降で対応しています。対応していないクライアントがあると、正しく動作しません。
- 以前にFSRSの「カスタムスケジューリング」版を使っていた場合は、FSRSを有効にする前に、カスタムスケジューリングの欄を空にしてください。

### 簡単な設定ガイド

- デッキオプション画面の下部にある「FSRS」セクションで有効にします。FSRSは全体に対してのみ有効にでき、一部のプリセットだけ有効にすることはできません。
- 学習ステップと再学習ステップをすべて1日未満にし、同じ日に終えられるようにします。23時間は1日未満ですが、最初の復習と同じ日に終えられないためおすすめしません。10分や30分などのステップが適しています。
- 「FSRSパラメーター」の下にある**最適化**ボタンをクリックします。「FSRSパラメーターは現在最適と思われます」と表示された場合も問題ありません。
- 希望保持率を設定します。これは、カードの復習期限が来たときに正しく思い出せる割合です。**FSRSで最も重要な設定です。希望保持率を上げると、間隔が短くなり、1日の復習回数が増えます。**初期設定の90%は、保持率と学習負担のバランスがよい値です。90%を超えると学習負担は急速に増え、97%を超えると負担が大きくなりすぎることがあります。[「最小推奨保持率を計算」](./#compute-minimum-recommended-retention)を使うと、希望保持率を決める参考になります。

パラメーターと希望保持率はプリセットごとに設定されます。異なる設定のプリセットを複数作ることもできます。

FSRSは、情報を忘れたときに**もう一度**ではなく**難しい**を押す習慣を除けば、ほぼどのような学習習慣にも適応できます。**難しい**を押すと、FSRSは、迷いや大きな努力があったとしても情報を正しく思い出せたと判断します。思い出せなかったときに**難しい**を押すと、間隔が適切でないほど長くなります。この習慣がある場合は改め、忘れたときには**もう一度**を使ってください。

アドオンとの互換性については、カードの間隔やスケジュールに影響するアドオンはFSRSと併用しない、というのが一般的な目安です。

### 希望保持率

希望保持率は、復習予定のカードを覚えている可能性を設定します。初期設定の90%では、次回の復習時にカードを思い出す可能性が90%になるようにスケジュールします。通常、復習時に約90%のカードを思い出し、約10%を忘れることになります。

希望保持率を調整したときに学習負担がどう変わるか、次のグラフに示します。

![希望保持率が1に近づくほど学習負担が指数関数的に増加するグラフ](/media/FSRS_retention.png)

グラフの正確な形は人によって異なりますが、全体的な傾向はおおむね同じです。希望保持率を低くすると、1日の復習は大幅に減りますが、忘れるカードは増えます。希望保持率が100%に近づくと、学習負担は急激に増えます。そのため、数値を調整するときは慎重に行い、97%未満にすることをおすすめします。

最新のAnkiでは、同じプリセット内でデッキごとに異なる希望保持率を設定できます。

### 設定の参考

**設定の参考（実験的機能）**では、異なる保持率での学習負担をシミュレーションできます。自分に合わせた保持率と学習負担のグラフを確認でき、希望保持率を選ぶ参考になります。

どのように使うか迷ったら、「1日に現実的に何枚復習できるか」「1日に復習へ何分使えるか」を考え、対応する学習負担のグラフから無理のない希望保持率を探してください。

また、現在の希望保持率での1日の復習数（または時間）と、希望保持率を変更した場合の数値を比べて、「より多く覚えるために、これだけ学習時間を増やしたいか」「覚える量が減っても、学習時間をこれだけ減らしたいか」と考える方法もあります。

シミュレーターについて詳しくは、[このセクション](./deck-options#the-simulator)を参照してください。

### FSRSパラメーター

FSRSパラメーターはカードのスケジュールに影響します。手動で変更したり、他の人の値をコピーしたりしないでください。

**FSRSパラメーターを最適化する**

FSRSの最適化機能は、機械学習を使って記憶の傾向を学習し、復習履歴に最も合うパラメーターを見つけます。最適な値を調整するには、複数回の復習履歴が必要です。

**最適化**ボタンをクリックすると、FSRSが復習履歴を分析し、記憶の傾向と学習内容に合うパラメーターを生成します。主観的な難易度が大きく異なるデッキがある場合は、別々のプリセットを割り当てることをおすすめします。易しいデッキと難しいデッキでは、適したパラメーターが異なるためです。頻繁に最適化する必要はありません。月に1回で十分です。

初期設定では、現在のプリセットを使うすべてのデッキの復習履歴をもとにパラメーターを計算します。最適化に使うカードを変えたい場合は、[検索](./searching)で対象を調整してから最適化することもできます。

**すべてのプリセットを最適化**をクリックすると、すべてのプリセットのパラメーターを一度に最適化できます。

**健全性チェック**

**最適化時に健全性をチェック（低速）**を有効にすると、FSRSが復習履歴にどれだけ適応できるかを確認できます。うまく適応できない主な理由は次のとおりです。

- 復習回数が少ない（数百回未満）。機械学習アルゴリズムであるFSRSが学習するには、データが必要です。
- [「難しい」の誤用](/manual/studying#answer-buttons)。答えを忘れた場合に**難しい**を使わないでください。これは不合格ではなく、正解の評価です。
- 答えを忘れたときに**もう一度**を使っていない。答えを忘れたときは**もう一度**、思い出せたときは**難しい**、**正解**、**簡単**を押すとAnkiは想定しています。

### 変更時にカードを再スケジュール

FSRSの有効化、希望保持率の変更、パラメーターの変更時にカードの期限日を変更するかを設定します。初期設定では再スケジュールしません。今後の復習には新しい設定が使われますが、学習負担はすぐには変わりません。有効にするとカードの期限日が変わります。希望保持率によっては期限を迎えるカードが大幅に増えることがあるため、SM-2から切り替えるときにこのオプションを使うことは**おすすめしません**。

このオプションを使うと各カードに復習履歴が追加され、コレクションのサイズが大きくなるため、必要な場合だけ使ってください。

SM-2から切り替える際にこのオプションを使う場合は、先にバックアップを作成し、FSRSを再スケジュール有効の状態で有効にしてください。その後、必要に応じて操作を取り消すか、バックアップから復元できます。

### 最小推奨保持率を計算（25.07より前） {#compute-minimum-recommended-retention}

<Warning>
  ***削除された機能***

この機能はAnki 25.07で削除されました。

</Warning>

最小推奨保持率の計算（CMRR）は、最短時間で最も多くの内容を学べる希望保持率を見つけようとします。計算結果は希望保持率を決めるときの参考になります。保持率を高めるために学習時間を増やしてもよければ、計算結果より高い希望保持率を選ぶこともできます。一方、最小値より低く設定することはおすすめしません。忘れる回数が増えて、必要以上に学習時間がかかるためです。

### シミュレーター

シミュレーターを使うと、1日の復習数または学習時間の目安を確認できます。

- **シミュレーション日数:** シミュレーションする学習履歴の期間を設定します。
- **シミュレーションする追加新規カード数:** このプリセットに現在含まれている数より多くのカードをシミュレーションするかを設定します。たとえば、このプリセットにカードが100枚あり、追加新規カード数を50にすると、合計150枚としてシミュレーションします。今後新規カードを追加する予定がある場合に便利です。
- **1日の新規カード数**と**1日の最大復習数:** 毎日学習する新規カード数と、1日に復習するカード数の上限を設定します。
- **最大間隔:** 間隔の最大日数を設定します。

シミュレーションをできるだけ実際に近づけるため、カードの実際の記憶状態（難易度、安定性、想起可能性）が考慮されます。FSRSのパラメーターと希望保持率も使われるため、それらを変更するとシミュレーション結果も変わります。

#### 学習ステップと再学習ステップ

FSRSでは、1日以上の（再）学習ステップはおすすめしません。従来のSM-2で長いステップが使われていた主な理由は、学習段階を終えたカードを何度も間違えると易しさが大きく下がり、一部の人が「易しさ地獄」と呼ぶ状態になることでした。FSRSではこの問題は起きません。学習ステップを1日未満にすると、FSRSは学習内容と記憶の状態に合わせて、適切と判断した時期にカードをスケジュールできます。長い学習ステップを避けるもう1つの理由は、FSRSが最初の復習を最後の学習ステップより短い間隔に設定する場合があるためです。その場合、**難しい**ボタンの間隔が**正解**より長くなることがあります。

学習ステップの数も最小限にすることをおすすめします。同じ日にカードを何度も繰り返しても、長期記憶への効果は大きくないという根拠があります。そのため、他のカードや短い学習時間に使うほうが有効です。

最新のAnkiでは、（再）学習ステップの欄を空にすると、短期的なスケジュールをFSRSに任せられます。これは実験的な機能です。FSRS-5が1日未満の間隔を設定できるからといって、必ずそうなるとは限りません。**もう一度**の間隔が1日以上になる場合もあります。

#### アドオンとの互換性

一部のアドオンはFSRSと競合する場合があります。一般的な目安として、カードの間隔に影響するアドオンはFSRSと併用しないでください。よく使われるアドオンとFSRSの互換性は、[アドオンとの互換性](https://github.com/open-spaced-repetition/fsrs4anki#add-on-compatibility)で確認できます。

#### その他

FSRSについてよくある質問への回答は、[FSRSのFAQ](/faqs/frequently-asked-questions-about-fsrs)を参照してください。

FSRSについて詳しくは、次のページをご覧ください。

- [FSRS4Anki Wiki](https://github.com/open-spaced-repetition/fsrs4anki/wiki)
- [GitHubのFSRS4Anki](https://github.com/open-spaced-repetition/fsrs4anki)

## 詳細

### 最大間隔

復習カードを再表示するまでの最大日数です。復習間隔が上限に達すると、**難しい**、**正解**、**簡単**のどれを選んでも同じ間隔になります。短く設定するほど学習負担は大きくなります。初期設定は100年です。保持率を高めるために学習時間を増やしてもよければ、より短い値にできます。

### 過去の保持率

この設定はFSRSが有効な場合だけ表示されます。

復習履歴の一部が欠けている場合、FSRSはその不足分を補う必要があります。初期設定では、過去の復習で内容の90%を覚えていたと仮定します。過去の保持率が90%よりかなり高かった、または低かった場合、このオプションを調整すると、FSRSが欠けた復習履歴をより正確に推定できます。

復習履歴が不完全になる理由は、主に2つあります。

- **指定日より前に復習したカードを無視**を使っている。
- 容量を空けるために以前の復習記録を削除した、または別のSRSプログラムからデータを読み込んだ。

後者はまれです。そのため、前者のオプションを使っていない場合は、この設定を調整する必要はほとんどありません。

### 指定日より前に復習したカードを無視

設定すると、指定日より前に復習したカードはFSRSパラメーターの最適化対象から除外されます。他の人のスケジュールデータを読み込んだ場合や、回答ボタンの使い方を変更した場合に便利です。

### 初期の易しさ

カードを学習開始時にどの程度易しいとするかを設定します。カードが初めて学習を終えて卒業するときに設定されます。初期設定は2.50です。カードの学習を終えた後、復習で**正解**を選ぶと間隔はおよそ2.5倍になります（たとえば、前回の間隔が10日なら、次は約25日です）。以降の復習での評価に応じて、易しさは初期値から増減します。

### 簡単ボーナス

復習カードで**簡単**を選んだとき、間隔に適用する追加の倍率です。初期設定は1.30です。**簡単**を選ぶと、**正解**の間隔の1.3倍になります（たとえば、**正解**の間隔が10日なら、**簡単**では約13日です）。

### 間隔の調整

すべての復習に適用する追加の倍率です。初期設定の1.00では変化しません。0.80に設定すると、通常の間隔の80%になります（たとえば、10日の間隔は8日になります）。この倍率を使って、復習頻度を増減できます。

中程度の難しさの内容では、平均的なユーザーは、復習時に成熟したカードのおよそ90%を思い出せるはずです。自分の成績を確認するには、デッキのグラフ/統計を開き、「回答ボタン」グラフの右側にある正解率を確認します。Ankiを使い始めてから日が浅い場合は、成熟したカードがまだないことがあります。新規カードや学習期間の短いカードの成績は大きく変動するため、保持率について判断する前に、成熟したカードをある程度復習することをおすすめします。

SuperMemoのウェブサイトでは、希望保持率に合う倍率を求める方法が紹介されています。式は次のとおりです。

```text
    log(希望保持率%) / log(現在の保持率%)
```

現在の保持率が85%で、90%に上げたい場合、調整倍率は次のように計算します。

```text
    log(90%) / log(85%) = 0.65
```

[検索エンジンで計算](<https://duckduckgo.com/?q=log(0.90)+%2F+log(0.85)>)できます。

計算結果の65%を間隔の調整に入力すると、時間の経過とともに保持率が希望する値に近づきます。

ただし、学習時間と保持率の関係は直線的ではありません。保持率を5ポイント上げるには、復習頻度を35%増やす必要があります。学習内容が非常に重要なら、そのために余分な努力をする価値があるかもしれません。判断はご自身で行ってください。忘れすぎていることが心配なだけなら、初期の学習段階に時間をかける、または記憶術を使うほうが、少ない負担で効果を得られる場合があります。

また、Ankiは新しい間隔を、以前の間隔より最低1日長く設定します。同じ間隔で復習し続ける状態を防ぐためです。複数日にわたってカードを1日1回復習したい場合は、この倍率を調整するのではなく、学習モードのステップを増やしてください。

### 「難しい」の間隔

**難しい**を選んだときに適用する倍率です。割合は前回の間隔に対する値です。たとえば初期設定の1.20では、間隔が10日のカードは12日後に表示されます。

### 新しい間隔

復習カードで**もう一度**を選んだときに適用する倍率です。初期設定の0.00では、忘れた復習カードの間隔は0に戻ります（[最小間隔](./#minimum-interval)を適用すると、その後1日になります）。

初期設定から変更すると、忘れたカードの以前の間隔の一部を保持できます。たとえば、間隔が100日のカードで**新しい間隔**を0.20にすると、新しい間隔は20日になります。

間隔の一部を保持するのは合理的に思えるかもしれませんが、SuperMemoの調査では、間隔の一部を保持すると[逆効果になる](https://supermemo.guru/wiki/Post-lapse_stability)ことが分かっています。そのため、初期設定のままにすることをおすすめします。

### カスタムスケジューリング

カスタムスケジューリング欄で独自のJavaScriptを使うと、Ankiのカードスケジュールを細かく調整できます。これは全体に適用される設定で、ここに入力したコードはすべてのプリセットに反映されます。

次はカスタムスケジューリングのスクリプト例です。Qt5版のAnkiでは、コードをトランスパイルする必要があります。

```javascript
// 既存の状態を出力する
console.log(JSON.stringify(states, null, 4));

// Webインスペクターが開いている場合はデバッガーを起動する
debugger;

// 「難しい」ボタンが学習ステップの場合、間隔を123分にする
if (states.hard.normal?.learning) {
    states.hard.normal.learning.scheduledSecs = 123 * 60;
}

// 再スケジュールするカスタム学習デッキでも同じ変更を適用する
if (states.hard.filtered?.rescheduling?.originalState?.learning) {
    states.hard.filtered.rescheduling.originalState.learning.scheduledSecs = 123 * 60;
}

// 復習で「簡単」を使ったとき、易しさ係数を0.2増やす
if (states.good.normal?.review) {
    states.easy.normal.review.easeFactor = states.good.normal.review.easeFactor + 0.2;
}
```
