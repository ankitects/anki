Windowsでは、画面への描画方法が3つあります。初期設定は「software」で、速度は遅いものの、互換性が最も高い方式です。ほかに、より高速な「OpenGL」と「ANGLE」があります。ただし、これらは動作しない場合や、メニューバーが消える、ウィンドウに何も表示されないといった問題を起こす場合があります。どの方式が最適かは、お使いのコンピューターによって異なります。

## 設定画面でのドライバーの変更

Anki 23.10以降では、「ツール → 設定」を開き、ドロップダウンメニューからグラフィックスドライバーを変更できます。

## コマンドラインでのドライバーの変更

表示に問題がある場合は、cmdで次のコマンドを実行し、ソフトウェアモードに切り替えてみてください。

```bat
echo software > %APPDATA%\Anki2\gldriver6
```

PowerShellでは、次のコマンドを使います。

```powershell
echo software > $env:APPDATA\Anki2\gldriver6
```

何も出力されません。その後、Ankiを起動し直してください。

初期設定に戻すには、`software`を`auto`に変更するか、このファイルを削除してください。

## 全画面表示

Anki 2.1.50以降には全画面表示モードがありますが、さまざまな問題があるため、`OpenGL`の使用中は無効になっています。上記の手順でソフトウェアレンダリングを有効にすると、全画面表示を使えます。ただし、描画性能が低下する可能性があります。

Anki 23.10以降では、初期設定のDirect3Dドライバーで全画面表示に対応しています。
