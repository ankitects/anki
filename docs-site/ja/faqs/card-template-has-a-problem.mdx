---
title: "カードテンプレートに問題があります"
---

最近の Anki は、カードテンプレートの誤りを以前より厳密に報告します。以前は一部の問題を通知せずに無視し、その結果、テンプレートが想定外の表示になっていました。この変更により、誤りに気づきやすくなりました。

自分でカードテンプレートを編集していない場合は、テンプレートを作成した共有デッキの作者に誤りがあった可能性があります。

カードテンプレート画面を開いて誤りを修正できます。

- デスクトップ版では、問題のあるカードを編集して **Cards...** ボタンをクリックします。
- AnkiMobile では、復習画面で問題のあるカードを表示し、歯車をタップして **Card Template** を選びます。

テンプレートを修正すると、そのタイプのカードすべてに反映されます。同じテンプレートを使うカードごとに変更する必要はありません。

必要な修正は、表示されたメッセージによって異なります。

**「`{{Field}}` が見つかりましたが、「Field」というフィールドはありません」**

テンプレートに存在しないフィールド名が含まれています。カードテンプレート内の `{{Field}}` を探し、削除してください。

**「`{{Field` の `}}` がありません」**

テンプレートに `{{` があるものの、対応する `}}` がない場合に表示されます。たとえば、次の内容は

```
{{Field
```

次のように修正します。

```
{{Field}}
```

**「`{{/Field}}` がありません」**

カードテンプレートに `{{#Field}}` または `{{^Field}}` があるのに、対応する `{{/Field}}` がありません。テンプレートから `{{#Field}}` または `{{^Field}}` を削除するとエラーが解消されます。

**「`{{/One}}` が見つかりましたが、`{{/Two}}` が必要です」**

条件付き置換は、開始した順序と同じ順序で閉じる必要があります。たとえば、次のテンプレートは誤りです。

```
{{#One}}
  {{#Two}}
    {{Three}}
  {{/One}}
{{/Two}}
```

次のように修正します。

```
{{#One}}
  {{#Two}}
    {{Three}}
  {{/Two}}
{{/One}}
```

**「`{{/Field}}` が見つかりましたが、`{{#Field}}` または `{{^Field}}` がありません」**

終了タグには対応する開始タグが必要です。次の例では、先頭に `{{#Two}}` または `{{^Two}}` がないため無効です。

```
  {{Field}}
{{/Two}}
```

終了タグを削除すると修正できます。

```
{{Field}}
```
