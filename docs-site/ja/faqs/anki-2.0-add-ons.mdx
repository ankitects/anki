---
title: "Anki 2.0 のアドオン"
---

**Anki 2.0 が使用しているライブラリはサポートが終了したため、[Anki 2.0 は提供を終了しました](/faqs/anki-2.0-support-has-ended)。今後の OS 更新で動作しなくなる可能性があります。Anki 2.1 への更新をご検討ください。**

使いたいアドオンに AnkiWeb 上の 2.0 用ダウンロードリンクがある場合は、アドオンの `.py` または `.zip` ファイルをダウンロードできます。

- `.py` ファイルの場合は、アドオンフォルダーに配置します。
- `.zip` ファイルの場合は、内容をアドオンフォルダーに展開します。

アドオンフォルダーはデータフォルダー内にあります。[ファイルの場所](/manual/files#file-locations)

以前の Anki 2.0 アドオンのアーカイブも利用できます。使い方は次のとおりです。

- [アドオンアーカイブ](https://apps.ankiweb.net/downloads/archive/addons-2.0.zip)をダウンロードします。
- ZIP ファイルを展開します。
- README ファイルで、使いたいアドオンの ID を確認します。
- `.py` ファイルの場合は、アドオンフォルダーに配置します。
- `.zip` ファイルの場合は、内容をアドオンフォルダーに展開します。

アドオンフォルダーはデータフォルダー内にあります。[ファイルの場所](/manual/files#file-locations)

**これらのアドオンは現状のまま提供され、サポートはありません。**
