## JavaScript

デスクトップ版に関する[注意事項](/manual/templates/styling#javascript)は、AnkiMobile にも当てはまります。

さらに、AnkiMobile でコードを使う場合は、タップ検出と適切に連携させる必要があります。`A` / `BUTTON` 要素や `onclick` ハンドラーを持つ要素へのタップは、想定どおりに動作します。

タップイベントを受け取る必要があるほかの要素には、`tappable` クラスを指定してください。AnkiMobile 2.0.39 以降で、その要素にタップを渡すよう指示できます。

## 再生ボタン

音声の再生ボタンのスタイルを変更するには、[音声の再生ボタン](/manual/templates/styling#audio-replay-buttons)をご覧ください。

## 画像のサイズ変更

写真ライブラリから画像を添付すると、最も長い辺が最大1024ピクセルになるよう自動でサイズが変更されます。

最近の Anki では、「**設定**」>「**一般**」画面でこの上限を変更し、クリップボードから貼り付けた画像にも上限を適用するかどうかを設定できます。
