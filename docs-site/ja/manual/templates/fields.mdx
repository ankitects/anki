## 基本的な置換

最も基本的なテンプレートは、次のようなものです。

```text
    {{Front}}
```

波かっこの中にテキストを置くと、Ankiはその名前のフィールドを探し、実際の内容に置き換えます。

フィールド名では大文字と小文字が区別されます。Frontという名前のフィールドに{{front}}と書いても、正しく動作しません。

テンプレートにはフィールド以外の任意のテキストも含められます。たとえば、首都を学習していて「Country」フィールドを持つノートタイプを作った場合、表面テンプレートを次のようにできます。

```text
    What's the capital city of {{Country}}?
```

初期設定の裏面テンプレートは、次のようになります。

```text
    {{FrontSide}}

    <hr id=answer>

    {{Back}}
```

これは「表面のテキストを表示し、区切り線を表示してから、Backフィールドを表示する」という意味です。

id=answerは、問題と解答の区切り位置をAnkiに知らせます。長いカードで「解答を表示」を押すと、解答が始まる位置まで自動的にスクロールします（画面の小さいモバイル端末で特に便利です）。解答の先頭に横線を表示したくない場合は、代わりに段落やdivなどのHTML要素を使えます。

## 改行

カードテンプレートはWebページと同じ仕組みなので、改行には専用のコードが必要です。たとえば、テンプレートに次のように書いても、

```text
    one
    two
```

プレビューでは次のように表示されます。

```text
    one two
```

改行するには、行末に&lt;br&gt;コードを追加します。

```text
    one<br>
    two
```

brは「(line) break（改行）」を表します。フィールドも同様です。2つのフィールドを別々の行に表示するには、次のようにします。

```text
    {{Field 1}}<br>
    {{Field 2}}
```

## フィールドごとの音声読み上げ

この機能にはAnki 2.1.20、AnkiMobile 2.0.56、またはAnkiDroid 2.17以降が必要です。

Frontフィールドを米国英語の音声で読み上げるには、カードテンプレートに次のように記述します。

```text
    {{tts en_US:Front}}
```

Windows、macOS、iOSではOSに組み込まれている音声が使われます。

Linux版AnkiにはTTSエンジンが付属していません。TTSアドオンをインストールするまでは、{{tts}}タグを含むカードに「no players found for TTSTag(...)」と表示されます。多くの場合、サンプルの[gTTSテキスト読み上げサポート](https://ankiweb.net/shared/info/391644525)アドオンで十分です。

1. **ツール → アドオン → アドオンを取得…** を選びます。
2. 391644525を貼り付けて「OK」をクリックします。
3. Ankiを再起動します。

アドオンをインストールしてAnkiを再起動すると、アドオンが対応する言語をTTSタグで使えます。

利用できる言語と音声の一覧を見るには、カードテンプレートに次のように記述します。

```text
    {{tts-voices:}}
```

選択した言語に対応する音声が複数ある場合は、一覧で使いたい音声を指定できます。Ankiは利用可能な音声のうち最初のものを選びます。例：

```text
    {{tts ja_JP voices=Apple_Otoya,Microsoft_Haruka:Field}}
```

Apple製デバイスではOtoyaを、Windows PCではHarukaを使います。

TTSの実装によっては読み上げ速度も指定できます。

```text
    {{tts fr_FR speed=0.8:SomeField}}
```

速度と音声の指定は省略できますが、言語は指定する必要があります。

Macでは、使用できる音声をカスタマイズできます。

- システム設定を開きます。
- 「アクセシビリティ」をクリックします。
- 「読み上げコンテンツ」をクリックします。
- システム音声のメニューを開き、「カスタマイズ」を選びます。

音声によって聞こえ方が異なるため、好みのものを試してください。Siriの音声はApple製アプリでしか使えません。新しい音声をインストールしたら、Ankiを再起動してください。

Windowsでは、Cortanaなど一部の音声を選べません。Microsoftが他のアプリに公開していないためです。

穴埋めノートタイプでは、cloze-onlyフィルターを使うと穴埋め部分だけを読み上げられます。

```text
    {{tts en_US:cloze-only:Text}}
```

cloze-onlyフィルターはAnki 2.1.29以降、AnkiMobile 2.0.65以降、AnkiDroid 2.17以降で使えます。

## 複数フィールドと固定テキストの読み上げ

この機能にはAnki 2.1.50以降、AnkiMobile 2.0.84以降、またはAnkiDroid 2.17以降が必要です。

テンプレートに含まれる複数のフィールドや固定テキストをTTSで読み上げるには、次のようにします。

```
[anki:tts lang=en_US] This text should be read. Here is {{Field1}} and {{Field2}}[/anki:tts]

This is other text on the template. It is outside of the tags so it should not be read.
```

## 特殊フィールド

テンプレートには、次の特殊フィールドを含められます。

```text
    ノートのタグ: {{Tags}}

    ノートタイプ: {{Type}}

    カードのデッキ: {{Deck}}

    カードのサブデッキ: {{Subdeck}}

    カードのフラグ: {{CardFlag}}

    カードの種類（「Forward」など）: {{Card}}

    表面テンプレートの内容
    （裏面テンプレートでのみ有効）: {{FrontSide}}
```

FrontSideを使っても、カード表面の音声は自動再生されません。表面と裏面の両方で同じ音声を自動再生するには、裏面にも音声フィールドを手動で含めてください。

ほかのフィールドと同様、特殊フィールド名でも大文字と小文字が区別されます。たとえば{{tags}}ではなく{{Tags}}を使う必要があります。

## ヒントフィールド

カードの表面または裏面にフィールドを追加し、明示的に表示するまで隠しておけます。これを「ヒントフィールド」と呼びます。ヒントを追加する前に、Ankiで問題に答えやすくするほど、実生活で同じ問題に出会ったときに思い出しにくくなる点に注意してください。作業を進める前に「最小情報の原則」について[こちら](https://super-memory.com/articles/20rules.htm)をお読みください。

ヒント用フィールドをまだ作成していない場合は、先に追加してください。方法が分からない場合は、[フィールド](../editing#customizing-fields)の節を参照してください。

MyFieldというフィールドを作成した場合、テンプレートに次のように記述すると、カードに含めたまま初期状態では隠しておけます。

```text
    {{hint:MyField}}
```

カードに「show hint」というリンクが表示されます。クリックするとフィールドの内容が表示されます（MyFieldが空なら何も表示されません）。

問題側でヒントを表示してから解答を表示すると、ヒントは再び隠れます。解答を表示したときにも常にヒントを表示したい場合は、裏面テンプレートから{{FrontSide}}を削除し、表示したいフィールドを手動で追加してください。

現時点では、音声にヒントフィールドを使えません。ヒントのリンクをクリックしたかどうかにかかわらず、音声は再生されます。

表示や動作をカスタマイズするには、ヒントフィールドを自分で実装する必要があります。その方法についてはサポートを提供できませんが、次のコードを参考にできます。

```text
    {{#Back}}
    <a class=hint href="#"
    onclick="this.style.display='none';document.getElementById('hint4753594160').style.display='inline-block';return false;">
    Show Back</a><div id="hint4753594160" class=hint style="display: none">{{Back}}</div>
    {{/Back}}
```

## 辞書へのリンク

フィールド置換を使って辞書へのリンクも作成できます。オンライン辞書が、次のようなURLでテキストを検索できるとします。

```text
    http://example.com/search?q=myword
```

テンプレートに次のように記述すれば、自動リンクを追加できます。

```text
    {{Expression}}

    <a href="http://example.com/search?q={{Expression}}">check in dictionary</a>
```

復習中にリンクをクリックすると、各ノートの語句を検索できます。ただし注意点があります。次の節を参照してください。

## HTMLの除去

テンプレートと同じように、フィールドの内容もHTMLとして保存されます。辞書リンクの例でExpressionに装飾なしの「myword」が含まれていれば、HTMLも「myword」のままです。しかし、書式を設定するとHTMLが追加されます。たとえば「myword」を太字にすると、実際のHTMLは「&lt;b&gt;myword&lt;/b&gt;」になります。

辞書リンクでは問題が起きることがあります。上の例ではリンクが次のようになります。

```text
    <a href="http://example.com/search?q=<b>myword</b>">check in dictionary</a>
```

リンク内の余計な文字を辞書サイトが正しく解釈できず、検索結果が表示されない可能性があります。

これを解決するため、Ankiではフィールド置換時に書式を除去できます。フィールド名の前にtext:を付けると、書式は含まれません。書式付きテキストでも機能する辞書リンクは次のとおりです。

```text
    <a href="http://example.com/search?q={{text:Expression}}">check in dictionary</a>
```

## 右から左に読むテキスト

右から左に読む言語を使う場合は、テンプレートを次のように調整します。

```text
    <div dir=rtl>{{FieldThatHasRTLTextInIt}}</div>
```

## ルビ文字

言語によっては、文字の読み方を示す注釈をテキストの上に付けます。この注釈は[ルビ文字](https://en.wikipedia.org/wiki/Ruby_character)と呼ばれます。日本語では[ふりがな](https://en.wikipedia.org/wiki/Furigana)と呼ばれます。

Ankiでルビ文字を表示するには、次の構文を使います。

```text
    Text[Ruby]
```

上記のテキストがMyFieldに入力されているとします。{{MyField}}を使うとフィールドの内容がそのまま表示されます。ルビ文字をテキストの上に正しく配置するには、テンプレートでfuriganaフィルターを使います。

```text
    {{furigana:MyField}}
```

例：

{/* prettier-ignore */}
| 入力テキスト | 表示結果 |
| ------------------- | ----------------------------------------------------------------------------------------- |
| Text[Ruby] | <ruby><rb>Text</rb><rt>Ruby</rt></ruby> |
| 日本語[にほんご] | <ruby><rb>日本語</rb><rt>にほんご</rt></ruby> |
| 世[よ]の 中[なか] | <ruby><rb>世</rb><rt>よ</rt></ruby>の<ruby><rb>中</rb><rt>なか</rt></ruby> |
| 世[よ]の中[なか] | <ruby><rb>世</rb><rt>よ</rt></ruby><ruby><rb>の中</rb><rt>なか</rt></ruby> （誤り） |

3つ目の例では「中」の前に空白があります。この空白は、ルビをその文字だけに適用するために必要です。空白がないと、4つ目の例のように「の」の上に誤ったルビが配置されます。

### ルビ文字用の追加フィルター

furiganaフィルターに加えて、kanaフィルターとkanjiフィルターを使い、ルビの一部だけを表示できます。kanaフィルターはルビだけを表示し、kanjiフィルターはルビをすべて取り除きます。

{/* prettier-ignore */}
| 入力テキスト | フィールドフィルター | 表示結果 |
| ------------------ | ---------------------- | --------------------------------------------- |
| 日本語[にほんご] | {{furigana:MyField}} | <ruby><rb>日本語</rb><rt>にほんご</rt></ruby> |
| 日本語[にほんご] | {{kana:MyField}} | にほんご |
| 日本語[にほんご] | {{kanji:MyField}} | 日本語 |

これらの名前も日本語に由来します。[かな](https://en.wikipedia.org/wiki/Kana)は単語の読みを表す表音文字体系を指し、[漢字](https://en.wikipedia.org/wiki/Kanji)は中国由来の文字を指します。

## メディアとLaTeX

テンプレート内のメディア参照を探す処理は時間がかかるため、Ankiはテンプレートをスキャンしません。テンプレートにメディアを含める場合は、次の点に注意してください。

### 固定の音声・画像

すべてのカードに同じ画像や音声（各カードの上部に表示する会社のロゴなど）を含める場合は、次のようにします。

1. ファイル名の先頭にアンダースコアを付けます（例：_logo.jpg）。アンダースコアにより、Ankiはそのファイルがテンプレートで使われていると認識し、デッキの共有時に書き出します。
2. 次のように、表面または裏面のテンプレートでメディアを参照します。

{/*  */}

```text
    <img src="_logo.jpg">
```

### フィールド内の参照

フィールドを使ったメディア参照には対応していません。復習中に表示されることはありますが、未使用メディアの確認、インポート、エクスポートなどでは機能しません。次の例は動作しません。

```text
    <img src="{{Expression}}.jpg">

    [sound:{{Word}}]

    [latex]{{Field 1}}[/latex]
```

代わりに、フィールド内にメディア参照を含めてください。詳しくは[インポート](../importing/text-files#importing-media)の節を参照してください。

## 解答の確認

この機能については、[動画](http://www.youtube.com/watch?v=5tYObQ3ocrw&yt:cc=on)でも解説しています。

解答の確認を簡単に試すには、カード追加画面の左上にある「基本」をクリックし、「基本（解答を入力）」を選びます。

共有デッキをダウンロードし、そのデッキで解答を入力したい場合は、カードテンプレートを編集できます。たとえば、テンプレートが次のようになっているとします。

```text
    {{Native Word}}

    {{FrontSide}}

    <hr id=answer>

    {{Foreign Word}}
```

外国語の単語を入力して正誤を確認するには、表面テンプレートを次のように編集します。

```text
    {{Native Word}}
    {{type:Foreign Word}}
```

比較したいフィールドの前にtype:を追加しています。FrontSideはカードの裏面にあるため、解答入力欄も裏面に表示されます。

復習中は解答を入力するテキスト欄が表示されます。Enterを押すか解答を表示すると、正解した部分と間違えた部分が示されます。テキスト欄のフォントサイズは、編集画面の「フィールド」ボタンから設定した、そのフィールドのサイズになります。

解答入力欄はプレビュー画面やAnkiWebには表示されません。

この機能はカードの解答方法を変更しません。どの程度覚えていたかは、自分で判断してください。

1枚のカードで使える入力比較は1つだけです。上記のコードを複数回追加しても動作しません。また、1行の入力にしか対応していないため、複数行のフィールドとの比較には適しません。

入力した解答と正解の位置をそろえるため、Ankiは比較表示に等幅フォントを使います。フォントを変更する場合は、スタイル欄の末尾に次のように記述します。

```text
    code#typeans { font-family: "myfontname"; }
```

次のHTMLに適用されます。

```text
    <code id=typeans>...</code>
```

上級者はCSSクラスtypeGood、typeBad、typeMissedを使って、正誤の表示色を変更できます。AnkiMobileはtypeGoodとtypeBadには対応していますが、typeMissedには対応していません。

フィールド画面でフォントを変えずに入力欄のサイズだけを変更するには、!importantを使って初期設定のインラインスタイルを上書きします。

```python
    #typeans { font-size: 50px !important; }
```

穴埋めカードでも解答を入力できます。表面と裏面の両方のテンプレートに{{type:cloze:Text}}を追加します。裏面は次のようになります。

```text
    {{cloze:Text}}
    {{type:cloze:Text}}
    {{Extra}}

```

複数の箇所が穴埋めされている場合は、テキスト欄で解答をカンマで区切ります。

### 発音区別符号を無視する

入力した文字の発音区別符号を正解と比較したくない場合は、フィールドにtype:ncを使います。

```text
    {{type:nc:Front}}
```

これにより、発音区別符号の違いは不正解と判定されません。たとえば「بطيخ」と「بَطِّيخ」、または「elite」と「élite」は同じものとして扱われます。

### 大文字と小文字を無視する

大文字と小文字をテスト対象にしない場合は、type:ciを使って区別せずに比較できます。

```text
{{type:ci:Front}}
```

フィールドにParisと入力されていても、parisと入力した解答は不正解になりません。正解は元の大文字・小文字を保って表示されます。

修飾子は順不同で組み合わせられます。発音区別符号と大文字・小文字の両方を無視するには、次のようにします。

```text
{{type:nc:ci:Front}}
```

clozeとも組み合わせられます。例：{{type:cloze:ci:Text}}
