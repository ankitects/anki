## 追加

カードをデッキに追加するには、復習中に「追加」ボタンをタップします。

画面上部の「タイプ」ボタンをタップすると、追加するノートのタイプを選べます。ノートタイプについては、[デスクトップ版マニュアルの概要](/manual/getting-started#note-types)をご覧ください。

フィールドをタップするとキーボードが表示され、情報を入力できます。「次へ」と「前へ」ボタンでフィールド間を移動できます。

ツールバーには次のアイコンがあります。

**B I U**\
テキストを太字、斜体、下線にします。

**Fx**\
書式を削除します。

**絵筆**\
テキストの色を設定します。

**クリップ/カメラ**\
カメラ、マイク、写真ライブラリ、またはファイルからメディアを追加します。iPad ではマイクボタンが別に表示されます。

**ペン**\
iPad でのみ利用できます。画像を描いてカードに添付できます。描いた画像を編集するには、2本の指で長押しします。

**平方根**\
下付き文字、上付き文字、[MathJax](./mathjax)へのショートカットです。

**目**\
復習時にカードがどのように表示されるかをプレビューします。

**\</\>**\
フィールドを構成する HTML を表示します。

ノートの内容を入力したら、保存ボタンをタップしてコレクションに追加します。

## 編集

ノートを編集するには、復習中に「編集」ボタンをタップします。

編集画面は前述の追加画面に似ていますが、次の点が異なります。

- ノートタイプとデッキを選ぶボタンはありません。既存ノートのタイプを変更するには、「ブラウズ」画面を開き、右上のチェックマークをタップしてカードを選び、「操作」>「ノートタイプを変更」を選択します。
- 画面上部に「ツール」ボタンがあります。タップすると、現在のカードまたはノートに対して操作を実行できます。各操作の説明は[操作の説明](./study-tools#actions)をご覧ください。

## ブラウズ

復習中に「ブラウズ」ボタンをタップすると、デッキを検索または閲覧できます。

既定では、ブラウザー画面に現在のデッキのすべてのカードが表示されます。

検索ボックスにテキストを入力すると、カードを絞り込めます。たとえば、現在のデッキから「hello」を含むカードだけを表示するには、検索語を `deck:current hello` にして Return キーをタップします。複数のデッキを検索する場合は、`deck:current` を削除してください。

AnkiMobile はデスクトップ版 Anki の検索文字列をすべてサポートしているため、複雑な検索もできます。例:

`tag:marked` 「marked」タグのカードを表示します。

`is:due` 復習期限が来ているカードだけを表示します。

`front:rabbit` 表面フィールドが正確に「rabbit」であるカードだけを表示します。

検索方法の一覧は、[デスクトップ版マニュアル](/manual/searching)をご覧ください。

「フィルター」ボタンをタップすると、コンピューター版のサイドバーのように、適用できるフィルターの一覧が表示されます。項目をタップすると現在の検索条件を置き換えます。項目をスワイプすると、既存の検索条件に追加できます。

「オプション」ボタンでは、左右の列に表示する内容や、カードの表示順を変更できます。

「選択」ボタンでは、複数のカードを選んで、デッキの変更や停止などの操作をまとめて実行できます。
