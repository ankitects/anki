## ビデオドライバーの変更

### 設定画面でのドライバーの変更

Anki 23.10以降で表示の問題やクラッシュが発生する場合は、「Anki → 設定」を開き、ドロップダウンメニューからビデオドライバーを変更してみてください。変更後はAnkiを再起動する必要があります。

### ターミナル.appでのドライバーの変更

古いバージョンのAnkiには設定画面にこの項目がありませんが、ターミナル.appを開き、次のコマンドを貼り付けて<kbd>Enter</kbd>キーを押すと、ドライバーを変更できます。

```
echo software > ~/Library/Application\ Support/Anki2/gldriver6
```

何も出力されません。その後、Ankiを起動し直してください。

初期設定に戻すには、`software`を`auto`に変更するか、このファイルを削除してください。

## eGPU

Macで外付けグラフィックスカードを使っていて画面に何も表示されない場合は、Ankiアプリを<kbd>Ctrl</kbd>キーを押しながらクリックし、「情報を見る」を開いて「外部GPUを優先」を有効にしてみてください。
