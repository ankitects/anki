ノートタイプの変更を保存するときやデッキを書き出すとき、Anki 2.1.45以降ではよくあるエラーがないか確認します。これらのエラーを残すと、該当するカードを学習するときに問題が起きるため、修正するまで処理を続けられません。

## 基本

先に[重要な概念](../getting-started#key-concepts)を確認してください。

以下のエラーの多くは、ノートタイプまたはカードテンプレートを変更すると解決します。次の手順で編集してください。

- ブラウザー画面を開き、左側の一覧を確認します。
- エラーメッセージに記載されたノートタイプを探します。必要に応じて、左上の検索欄を使ってください。
- ノートタイプをクリックすると、右側にそのカードとノートが表示されます。
- 編集領域の上部にある「カード...」ボタンをクリックし、[テンプレート画面](./intro#the-templates-screen)を開きます。

## 個別の問題

### テンプレートの構文エラー

このエラーは、[フィールド置換](./fields)の構文が正しくないことを示します。

テンプレートの誤りは、カードテンプレート画面を開いて修正できます。

- デスクトップ版では、問題のあるカードを編集してから「カード...」ボタンをクリックします。
- AnkiMobileでは、学習画面で問題のあるカードを表示し、歯車アイコンをタップして「カードテンプレート」を選びます。

誤りを修正すると、そのカードタイプのすべてのカードに反映されます。同じテンプレートを使うカードごとに変更する必要はありません。

変更内容は、表示されたメッセージによって異なります。

**'\{\{Field\}\}'が見つかりましたが、'Field'というフィールドはありません**

テンプレートに、存在しないフィールド名が含まれています。カードテンプレート内の`{{Field}}`を探して削除してください。

**\{\{Fieldの中に\}\}がありません**

テンプレート内に`{{`があるものの、対応する`}}`がない場合に表示されます。たとえば、

```
{{Field
```

となっている場合は、次のように修正します。

```
{{Field}}
```

**\{\{/Field\}\}がありません**

カードテンプレートに`{{#Field}}`または`{{^Field}}`があるものの、対応する`{{/Field}}`が見つからないことを示します。テンプレートから`{{#Field}}`または`{{^Field}}`を削除すると解決します。

**'\{\{/One\}\}'が見つかりましたが、'\{\{/Two\}\}'が必要です**

条件付き置換は、開始した順序と同じ順序で閉じる必要があります。たとえば、次のテンプレートは正しくありません。

```
{{#One}}
  {{#Two}}
    {{Three}}
  {{/One}}
{{/Two}}
```

次のように修正してください。

```
{{#One}}
  {{#Two}}
    {{Three}}
  {{/Two}}
{{/One}}
```

**'\{\{/Field\}\}'が見つかりましたが、'\{\{#Field\}\}'または'\{\{^Field\}\}'がありません**

閉じタグには対応する開始タグが必要です。たとえば、次の例では冒頭に`{{#Two}}`も`{{^Two}}`もないため、正しくありません。

```
  {{Field}}
{{/Two}}
```

閉じタグを削除すれば修正できます。

```
{{Field}}
```

### 表面が同じカード

入力内容ごとに、同じ問題のカードが2枚作成される設定になっています。カードタイプを追加したあと、設定を変更していない場合などに起こります。同じカードが重複すると学習量が増え、Ankiのスケジュール機能の効果も下がります。

[テンプレート画面](./intro#the-templates-screen)を開き、上部で重複しているカードタイプを選択します。右上のボタンからそのカードタイプを削除してください。そのカードタイプを使っていた重複カードとノートもすべて削除されます。

### カードの表面が空

<div id="no-field-replacement-on-front-side" />

Ankiは入力されたフィールドと、カードの表面・裏面に表示するフィールドを指定したテンプレートを組み合わせてカードを表示します。カードの表面が空だというメッセージが表示された場合、表面テンプレートに含まれるフィールドがすべて空か、テキストが入力されたフィールドが表面テンプレートに含まれていません。

デスクトップ版でカードを編集し、「カード...」をクリックして、テキストが入力されているフィールドが少なくとも1つ、表面テンプレートに含まれていることを確認してください。「フィールドを追加」ボタンからフィールドを追加できます。

穴埋めノートタイプを使っている場合は、「テキスト」フィールドに1つ以上の穴埋め削除を含めてください。例：\{\{c1::穴埋めにするテキスト\}\}

解答入力機能を使っている場合は、表面に別のフィールドも含めてください。

### 穴埋めノートタイプに穴埋めフィルターがない

<div id="no-cloze-filter-on-cloze-notetype" />

穴埋めノートタイプの表面テンプレートと裏面テンプレートには、[穴埋め](../editing#cloze-deletion)フィルターが必要です。フィルターがない場合、Ankiが穴埋めカードを正しく作成できるよう、追加し直してください。

#### 一部のカードが空になる

穴埋めでは、番号ごとに別のカードが作られます。たとえば、次の例では3枚のカードが作成されます。

```
{{c1::This}} is a {{c2::sample}} {{c3::sentence}}.
```

あとからテキストを編集して穴埋め番号を削除または変更すると、以前作成されたカードが空になることがあります。たとえば、次のどちらの変更でもカード3が空になります。

```
{{c1::This}} is a {{c2::sample}}
```

および

```
{{c1::This}} is a {{c2::sample}} {{c1::sentence}}.
```

カード3を表示すると、空であることを示すメッセージが表示されます。「空のカード」機能で削除できます。デスクトップ版のメインウィンドウでツールメニューからこの機能を開き、空のカードを削除してください。処理を進める前に、一覧に表示されたカードを確認してください。判断に迷う場合は、ファイル → 書き出しからバックアップを作成してください。

#### すべての穴埋めカードが空になる

カードテンプレートを誤って変更すると、穴埋め削除がまったく表示されなくなることがあります。その場合、問題のカードを1枚編集し、最初のフィールド名を確認してください。通常は「テキスト」です。その後、次の手順で修正します。

- 「カード...」ボタンをクリックします。
- 表面のテキストを次の内容に置き換えます。

    ```
    {{cloze:Text}}
    ```

- 裏面のテキストも同じ内容に置き換えます。

フィールド名がText以外の場合は、Textを実際のフィールド名に置き換えてください。
