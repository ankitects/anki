## Eski versiyalar uchun hujjatlar

Anki'ni hali yangilamagan bo'lsangiz, ushbu qo'llanmaning eski nusxalarini [Internet Archive](https://web.archive.org/web/20240829022941/https://docs.ankiweb.net/) saytidan topishingiz mumkin.

Kartalar qachon takrorlanishini belgilovchi tizimning (scheduler) eski versiyalari haqida bilmoqchi bo'lsangiz, [ushbu FAQ](/faqs/the-anki-2.1-scheduler) sahifasiga qarang.
