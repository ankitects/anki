## アクセス権限の問題

「access denied」というメッセージが表示される場合は、Ankiの一部のファイルが読み取り専用に設定され、Ankiから書き込めなくなっている可能性があります。

この問題を解決するには、次の手順を試してください。

- スタートバーの検索欄に`cmd.exe`と入力し、<kbd>Enter</kbd>キーを押します。
- 開いたウィンドウで次のコマンドを入力し、<kbd>Enter</kbd>キーを押してユーザー名を確認します。

whoami

- 次のコマンドを1行ずつ入力し、その都度<kbd>Enter</kbd>キーを押します。\_\_\_\_は、先ほど確認したユーザー名に置き換えてください。:Fの部分は残してください。

cd %APPDATA%

icacls Anki2 /grant \_\_\_\_:F /t

このコマンドでAnkiのデータフォルダーのアクセス権限が修正され、Ankiを起動できるようになるはずです。

## ウイルス対策・ファイアウォール・マルウェア対策ソフト

コンピューターにインストールされたセキュリティソフトが原因で、「permission denied」や「readonly」というエラーが発生したという報告があります。Ankiを例外に追加するか、原因かどうかを確かめるために、セキュリティソフトを一時的に無効にする必要があるかもしれません。ソフトを無効にするだけでは解決せず、Ankiを例外に追加するか、ソフトをアンインストールする必要があったという報告もあります。

## アクセス権限の問題の調査

ウイルス対策ソフトなどが原因でないことを確認し、上記の権限修正手順を実行しても問題が続き、OneDriveも使っていない場合は、`cmd.exe`で次のコマンドを実行してください。1行ごとに<kbd>Enter</kbd>キーを押します。

whoami

cd %APPDATA%

icacls Anki2 /t

表示された内容をコピーするか、スクリーンショットを撮り、サポートチケットに添えてAnkiのサポートに送ってください。
