---
title: "ライブラリの不足"
---

Ankiが起動しない場合は、ターミナルで`anki`を実行してください。ライブラリが見つからないと表示されたら、そのライブラリをインストールして、もう一度試してください。

利用できるプラットフォームがないというエラーが表示された場合は、次のコマンドでAnkiを起動してください。不足しているライブラリが分かるはずです。

```shell
QT_DEBUG_PLUGINS=1 anki
```

`apt-get`などでライブラリをインストールした後、同じ手順を繰り返してください。必要なライブラリがすべてそろうまで、何度か繰り返す必要があるかもしれません。
