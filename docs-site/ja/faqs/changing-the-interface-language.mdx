---
title: "画面の表示言語を変更する"
---

Anki は初回起動時に選択した言語で、メニューやダイアログなどの画面上のテキストを表示します。選択を間違えた場合や複数の言語を使いたい場合は、Anki の設定画面で変更できます（Windows/Linux では Ctrl+P、OS X では Cmd+,）。新しい言語を選んだ後、Anki を再起動すると反映されます。

Anki を使い始めたばかりの場合は、再起動後に **File > Switch Profile** を使って新しいプロフィールを作成してください。そうしないと、フィールド名などが以前の言語のままになることがあります。
