---
title: "録音時にエラーが発生する"
---

Anki で録音できない場合は、次の点を確認してください。

- マイクがパソコンに接続されている
- システムのサウンド設定で、マイクが既定の録音デバイスに設定されている
- Skype など別のプログラムがマイクを使用していない。別のプログラムを終了しても解決しない場合は、パソコンを再起動してください。

Windows 10 で `IOError: [Errno Unanticipated host error] -9999` と表示される場合は、Anki にマイクの使用を許可しているか確認してください。
