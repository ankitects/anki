## Fcitx

Anki'ning standart buildida fcitx qoʻllab-quvvatlashi bor, lekin u barcha
distributivlarda ishlamasligi mumkin. Agar fcitx'dan foydalana olmasangiz,
buning oʻrniga Anki'ni [Python wheel](/releases/betas/intro#via-pypi/pip)
paketlaridan ishga tushirib koʻrishingiz mumkin.
