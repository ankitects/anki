title: "URL スキーム"
---

AnkiMobile は、サードパーティーの辞書を開いたり、ほかのアプリから AnkiMobile に内容を追加したりするための URL スキームに対応しています。

## AnkiMobile の URL スキーム

### ノートを追加する

「URL スキーム」はウェブサイトへのリンクに似ていますが、アプリを開くリンクです。簡単な例:

```text
anki://
```

端末の Safari に入力すると、AnkiMobile が開きます。

AnkiMobile 2.0.30 以降では、コレクションに新しいノートを追加するスキームが用意されています。URL スキームでほかのアプリを呼び出せる辞書アプリや、[ショートカット](https://support.apple.com/guide/shortcuts/welcome/ios)などの自動化アプリで使えます。

カードを追加するスキームは次のとおりです。

```text
anki://x-callback-url/addnote?profile=User%201&type=Basic&deck=Default&fldFront=front%20text&fldBack=back%20text
```

最初の部分は必ず必要です。

```text
anki://x-callback-url/addnote?
```

続けて、アンパサンドでキーと値を区切ります。次のキーは必ず指定してください。

- `type=<ノートタイプ名>`
- `deck=<デッキ名>`
    - 入れ子のデッキは `::` で区切ります。

```text
- `deck=<デッキ名>::<サブデッキ名>`
```

フィールドを指定するには、名前の前に `fld` を付けます。たとえば、最初のフィールド名が「Text」の場合、キーは `fldText` です。フィールドのテキストは HTML として解釈されるため、改行を入れるには `"line 1\<br\>line 2"` のようにします。

URL 内の特殊文字はエスケープする必要があります。たとえば、フィールドにスペースが含まれる場合は `%20` として表します。ショートカットアプリには URL エンコード操作があり、便利です。

以下のキーは任意です。

- `profile=<プロファイル名>`

指定したプロファイルが現在有効でない場合、追加は失敗します。

- `tags=<スペースで区切ったタグ>`
- `dupes=1` - 指定すると、同じ内容のノートがすでにあってもノートを追加します。
- `x-success=<別のアプリの URL スキーム>` - ノートを追加した後、自動的に別のアプリに戻ります。

指定したフィールドが画像または音声ファイルへのリンクの場合、AnkiMobile はメディアを自動でダウンロードし、フィールドにリンクを追加します。例:

```text
fldFront=http://example.com/image.jpg
```

リンクの末尾が認識可能なファイル拡張子の場合のみダウンロードされます。リンク先が動的なウェブページの場合は、`http://example.com/getImage?imgID=1234&fakePath=foo.jpg` のように、末尾に拡張子を持つダミーの引数を追加できます。URL スキームに含める前に URL をエスケープしてください。エスケープしないと `?` と `&` が URL ではなく URL スキームの一部として解釈されます。

### 追加用の情報

サードパーティーアプリがプロファイル名、デッキ名、ノートタイプ名を取得し、ユーザーに分かりやすく表示できるよう、別の URL スキームも用意されています。

アプリから次の URL を呼び出します。

`anki://x-callback-url/infoForAdding?x-success=...`

ユーザーがリクエストを許可すると、要求されたデータがクリップボードに保存され、次のコードで取得できます。データを取得したら、クリップボードを消去してください。

```swift
let PASTEBOARD_TYPE = "net.ankimobile.json"
if let data = UIPasteboard.general.data(forPasteboardType: PASTEBOARD_TYPE) {
   // クリップボードを消去
   UIPasteboard.general.setData(Data(), forPasteboardType: PASTEBOARD_TYPE)
   // ... JSON を処理
}
```

### 検索

AnkiMobile 2.0.90 以降で利用できます。指定した検索文字列で検索を開きます。

`anki://x-callback-url/search?query=...`

### 同期

AnkiMobile 2.0.90 以降で利用できます。「同期」ボタンをタップした場合と同じ操作を実行します。

`anki://x-callback-url/sync`

## 辞書へのリンク

デスクトップ版 Anki では、フィールドの内容に基づいてウェブページを開けます。オンライン辞書サイトへのリンクを簡単に作成できます。詳しくはマニュアルの[こちらのセクション](/manual/templates/fields#dictionary-links)で説明していますが、リンク先の説明は前提知識が必要なため、まず[カードとテンプレート](/manual/templates/intro)のセクションをご覧ください。

デスクトップ版と同様に、AnkiMobile でも辞書サイトへのリンクを使えます。さらに、URL スキームを使って端末にインストールされている別の辞書アプリにリンクすることもできます。

辞書アプリによっては、検索する語句を指定できる URL スキームがあります。たとえば、iDict+ というアプリでは次の形式を使えます。

```text
idictplus://?search=mysearchtext
```

iDict+ をインストールした状態で Safari に入力すると、iDict+ が開き、「mysearchtext」をすぐに検索します。

iDict+ は、戻り先のリンクも指定できます。上記を次のように変更します。

```text
idictplus://?search=txt&scheme=anki://
```

Safari に入力すると、前と同じように「mysearchtext」を検索します。さらに「戻る」ボタンが表示され、タップすると Anki が開きます。

このテキストと上記のデスクトップ版の説明を組み合わせると、カード上のリンクから別のアプリで単語を検索し、検索後に Anki に戻ることができます。

残念ながら、URL スキームに標準はありません。対応しているアプリもあれば、対応していないアプリもあり、実装方法もアプリによって異なります。たとえば「Kotoba!」というアプリでは、次の URL スキームを使います。

```text
kotoba://dictionary?word=mysearchtext
```

アプリ名だけでなく、その後に続く文字列も異なります。また、Kotoba! から起動元のアプリに自動で戻る機能はありません。そのため、ホームボタンを2回押し、手動で AnkiMobile に戻る必要があります。

辞書アプリによっては、ドキュメントに URL スキームが記載されています。使っている辞書アプリに記載がない場合は、開発者に問い合わせてください。
